## 결과와 결정

**native 실행과 원시 기록 감사는 완료했지만, 후보는 사전 개발 기준을 넘지 못했다.**
기준선의 근거 포함 정답 15/20에 비해 후보는 16/20이었다. 요구한 순증 2개에 못 미친 순증 1개라서 후보를 승격하지 않았다. **미노출 평가 18문항은 열지 않았다.** 기준이나 참조 답을 결과에 맞춰 바꾸지 않았다.

## 고정했던 비교 계약

- 기존 quality-v2 reasoned 프로그램 바이트와 일반 개입/순위/기전/endpoint/인용 규칙을 추가한 후보를 비교했다. 특정 진단 문항 ID·정답을 후보 문구에 넣지 않았다.
- 양쪽 모두 source comparison→최종 판정의 두 단계이며, 같은 모델 등록·sampling·출력 상한·완전한 source_judgment_tail을 사용했다. 개별 규칙의 인과 기여를 분리한 ablation은 아니다.
- 이미 노출된 문헌 12개와 작성 경계 8개가 개발 집합이다. 통과 시에만 새 그룹 18개(라벨별 6개)를 여는 순서를 고정했다.
- 개발 기준: 20쌍 완전성, 근거 정답 순증 ≥2, 라벨 순증 ≥1, 라벨 회귀 ≤1, 작성 경계 ≥7/8. 이번에는 근거 정답 순증 조건만 충족하지 못했다.
- 원문·주장·connected group의 이전 노출을 제외한 별도 평가 집합을 준비했다. 이번 새 문항의 모델 실행/평가 결과는 0개다. 공개 자료의 기반 모델 사전학습 미노출은 확인되지 않았다.
- 최대 152 completions·1,200,000 tokens·2시간 중 실제 80 completions·207,581 tokens를 사용했다. 두 arm 모두 FROZEN_AUDIT이며 이 결과는 W 학습 효능 평가가 아니다.

모델 등록명은 `qwen3-4b-real`, 응답 fingerprint는 `vllm-0.25.1-697a994d` 하나였다. 이 값은 weight checkpoint의 암호학적 인증이 아니다. sampling은 temperature=.7, top_p=.8, seed=20261104, 출력 상한 384 tokens였다. 실행 환경은 Node v24.20.0, Effect 3.22.1, TypeScript 5.9.3이다.

## 실제 검증

연구 TypeScript 검사와 사전검사 6개가 통과했다. 사전검사에는 데이터 분리·정답 필드 비전송·gate 반례와 실제 native 두 저장소의 교대 사용/프로그램 격리/canonical 상태 불변 검사가 포함된다. 이는 scripted fixture이며 실모델 점수와 구별한다.

실모델 실험에서는 등록과 bounded reachability 확인 뒤 두 개의 새 isolated store를 초기화했다. 개발 종료 후 원시 request/response, native CAS의 trace·request·response 결속, 판정·비용·frozen canonical state를 다시 감사했다. `nativeWireVerified=true`, 각 arm의 감사 `nativeSubmissions=0`을 확인했다. 실행 증거와 감사 자료의 추가 저장은 canonical W 변경과 구분한다.

독립 집계에서도 20쌍·2개 개선/1개 회귀·토큰 합이 일치했다. test 행과 evaluate-started 표시는 없고, 전송 message에서 새 문항의 전체 질문 문자열 일치는 0개였다. 이 문자열 검사는 의미적 미노출이나 사전학습 미노출의 증명은 아니다.

- 사전검사 관리 실행: `a7d3977156364095b894c60ac19eb64a`, exit 0.
- 실제 비교 관리 실행: `d59d9c4c49be4d0e81e7817e688c9711`, 2026-11-15 06:12:53~06:23:00 UTC, exit 0.
- managed workload: RAM 2 GiB, swap 0, bulk 성장 상한 512 MiB. 이것은 모델 서버의 RAM/GPU 사용량 측정이 아니다.
- 원 관측은 로컬 `.hswm-local/semantic-repair-20261115/`에서 소유 artifact로 연결한다. private access/connection 정보는 이 문서에 복제하지 않는다.
