파일은 저장소·커밋·경로·내용 해시로 구분합니다. 같은 UID가 여러 문서에 나타나면 각 원문 위치를 보존합니다. 같은 바이트라는 사실은 같은 개념이라는 판정이 아닙니다.

HSWM의 로컬 브랜치·태그·원격 추적 참조에서 도달하는 커밋을 포함합니다. 다른 저장소는 HSWM이라는 문자열이 현재 경로나 내용에 있는 자료와 그 경로 이력을 선별했습니다. 타 저장소의 커밋 목록에는 해당 저장소의 다른 작업도 포함됩니다.

라이브 KG는 제한된 검색·이웃 조회의 관측입니다. 전체 덤프가 아니며, ACTIVE·PROPOSED·RETIRED·UNSPECIFIED 상태를 합치지 않습니다. 현재 파일 관측은 고정 Git 판본과 분리했습니다. 원격 전용 자료·비공개 대화·무시된 실행 payload는 이번 원문 수집에 포함하지 않았습니다.

SHACL과 원문 해시 검사는 연결 구조·바이트에 대한 검사입니다. HSWM 학습, 실행 권한 또는 효능의 증거로 승격하지 않습니다. 이 HTML은 네트워크 요청 없이 작동하며 원문 복원은 검증된 CLI 명령을 이용합니다.
