## 0. 권위와 과학적 경계

사용자가 직접 확정한 연구 방향은 다음 세 가지다.

1. 최종 HSWM을 작은 memory, KG, harness, local learner 또는 substrate로 축소하지 않는다.
2. 한 알고리즘이나 방법론이 실패하면 그 실패를 보존하고 다른 경로로 우회한다.
3. 알고리즘과 방법론을 바꾸어 가면서 최종 HSWM의 실현을 계속 추구한다.

이것은 **목표에 대한 연구 commitment**다. HSWM이 이미 존재한다는 관측, 반드시 성공한다는
예측, 특정 기전이 참이라는 판정 또는 반증을 면제하는 선언이 아니다. 아래 target invariant,
auxiliary hypothesis, evidence lineage, reroute transaction과 anti-immunization 규칙은 원문을
연구 가능한 형태로 닫는 `SECONDARY_AI` 형식화다.

따라서 두 문장은 동시에 참이어야 한다.

> **최종 목표는 축소하지 않는다.**

> **각 경험적 기전과 공개 주장은 독립적으로 `RED`, `UNDERDETERMINED` 또는 기각될 수 있다.**

## 1. 유지하는 target invariant

이 문서는 기존 HSWM 정체성이나 FCL 법칙을 새로 발명하거나 바꾸지 않는다. 다음 참조를
연구 경로가 보존해야 할 target invariant로 선언한다.

이 2026-08-30 원문이 직접 확정한 것은 `TI-1`의 목표 지속과 방법 교체 방향뿐이다.
`TI-2`부터 `TI-5`, 여덟 FCL과 그 claim ceiling은 각각 Constitution, fractal cognitive
composition canon 및 scientific-connections projection의 기존 bytes에서 온다. 이 문서는
그 기존 정본을 보존 대상으로 참조할 뿐, 새 원문이 그 상세를 다시 사용자 ratification한
것처럼 취급하지 않는다.

| ID | 보존 대상 | 지위와 경계 |
|---|---|---|
| `TI-1` | 하나의 token-native LLM-function macro-neural HSWM | `USER_PRIMARY` target identity이며 현재 구현 완료 주장이 아니다. |
| `TI-2` | evolving canonical hypergraph가 living harness, world/self model과 continuous learner의 역할을 함께 수행 | 서로 붙인 subsystem 목록으로 축소하지 않는다. 효능은 `UNJUDGED`다. |
| `TI-3` | `outcome → credit → owner/Permit-valid canonical revision → fresh behavior`의 인과 폐루프 | exact intervention과 대조군을 통과해야 하는 경험적 target이다. |
| `TI-4` | cognition-bearing HSWM이 상위 HSWM의 cell이 되고 같은 `Step / Learn / Inv / Permit / lineage` 문법으로 다시 합성 | FCL-1부터 FCL-8까지의 bounded operational obligation이다. 무한 scale·의식·personhood 주장이 아니다. |
| `TI-5` | 구성원 차이, provenance, 책임 주소, permission, consent, exit와 복구 가능성 | 거대화가 평탄화·권리 소거·중앙 commander로 퇴행하지 않게 하는 정체성 경계다. |

`TI-1`부터 `TI-5`는 성공한 자연법칙이라는 뜻의 invariant가 아니다. **연구 프로그램이 만들고
검증하려는 대상의 동일성 조건**이다. 어느 현 구현도 이 표만으로 target을 실현하지 않는다.

## 2. 교체할 수 있는 realization path

목표를 실현하는 다음 항목은 정본 정체성이 아니라 교체 가능한 auxiliary hypothesis다.

- foundation model, checkpoint, tokenizer, embedding과 context strategy;
- graph, metagraph, database, event store, queue와 runtime backend;
- memory, retrieval, reflection, skill과 world-model substrate;
- outcome source와 credit estimator;
- canonical revision proposal, admission, compilation과 mediation algorithm;
- coalition ignition, role assignment와 n-ary interaction algorithm;
- topology growth, prune, split, merge, repair와 morphogenesis rule;
- self-model, lineage, migration, fork·merge와 recovery mechanism;
- benchmark, task family, simulator, evaluator와 statistical method;
- G0–G6를 포함한 현재 연구 순서의 세부 구현과 instrument.

현재 가장 좋은 경로는 사용할 수 있지만 영구 정본으로 만들지 않는다. 경로를 바꿀 때에도
target invariant, 독립 outcome, 정확한 intervention, 강한 대조군, `Inv`/`Permit`, evidence
lineage와 claim ceiling을 약화할 수 없다.

## 3. 실패의 정확한 의미

실패는 범위를 가진다.

| 관측 | 허용되는 판정 | target에 미치는 영향 |
|---|---|---|
| 유효한 실험에서 선언한 mechanism이 대조군과 분리되지 않음 | `RED_WITHIN_SCOPE` | 해당 mechanism family와 경로를 종료·교체한다. HSWM target의 성공 증거는 생기지 않으며 target commitment는 유지한다. |
| task 포화, outcome 누수, 측정 불능 또는 instrument drift | `UNDERDETERMINED` | 효능 판정 없이 task·instrument·method를 교체한다. |
| bounded 효과가 remove/restore와 독립 재현을 통과 | `SUPPORTED_WITHIN_SCOPE` | 그 mechanism과 범위만 유지한다. 전체 HSWM이나 다음 scale을 자동 승인하지 않는다. |
| 상위 합성이 wrapper·federation·central control과 분리되지 않음 | `COMPOSITION_PATH_RED_WITHIN_SCOPE` | 시험한 composite boundary와 합성 algorithm을 교체한다. FCL-8은 계속 `UNJUDGED`이며 양성으로 기록하지 않는다. |

음성 결과는 목표를 축소하지 않지만, 실패한 기전을 계속 살아 있는 성공 경로처럼 취급할
권한도 주지 않는다. 폐기된 기전을 다시 쓰려면 새 evidence나 명시적 conceptual delta가 있는
successor hypothesis로 돌아와야 한다.

## 4. 우회는 lineage-preserving transaction이다

허용되는 reroute는 다음 순서를 가진다.

```text
declared route와 falsification contract
→ sealed outcome·control evidence
→ SUPPORTED / RED / UNDERDETERMINED 판정
→ 실패한 auxiliary hypothesis와 실패 범위 분리
→ 이전 bytes·결정·음성 증거 보존
→ 새 mechanism의 conceptual delta와 예상 구제 원인 명시
→ 동일하거나 더 강한 성공기준·대조군으로 새 contract 사전등록
→ 새 경로 실행과 독립 재현
```

새 경로는 predecessor UID, 실패 evidence UID, 보존하는 target invariant, 바꾸는 mechanism,
바꾸지 않는 claim ceiling과 새 판별 실험을 주소화해야 한다. 과거 기록을 수정해 현재 경로를
원래 계획이었던 것처럼 만들지 않는다.

## 5. 우회가 아닌 면역화

다음은 이 정본이 허용하는 우회가 아니다.

- outcome을 본 뒤 metric, threshold, baseline, holdout 또는 stopping rule을 바꾸는 것;
- 실패한 RAG, workflow, graph 또는 agent team에 새 HSWM 이름을 붙여 성공으로 재기록하는 것;
- G1 실패를 더 큰 graph·더 많은 agent·상위 scale 결과로 구제하는 것;
- 이전 `RED`, invalid run, 비용과 부작용을 삭제하거나 최신 문서에서 연결을 끊는 것;
- 새 경로에서 대조군, budget matching, 독립 outcome 또는 remove/restore를 약화하는 것;
- ontology·문서·test·receipt의 증가를 cognition이나 efficacy로 계산하는 것;
- 학습 편의를 위해 identity invariant, permission, consent, exit 또는 rollback을 우회하는 것.

이 금지는 target을 포기하기 위한 장치가 아니라, **목표에 도달했다고 잘못 선언하지 않고도
오래 탐색하기 위한 조건**이다.

## 6. FCL과 현재 연구 spine의 관계

FCL-1부터 FCL-8은 최종 fractal HSWM이 충족해야 할 target-side 판별 축이다. 현재
[`causal-composition research program`](../../_research/causal_composition/)의 G0–G6는 이 축을
검증하는 활성 경로지만 유일한 영구 방법론은 아니다.

- downstream gate는 upstream 실패를 사후에 구제하지 못한다;
- 실패한 gate mechanism은 predecessor로 돌아가 새 방법으로 다시 시험할 수 있다;
- gate 순서나 instrument를 바꾸려면 어떤 식별 문제를 개선하는지와 기존 control을 어떻게
  보존하는지를 먼저 기록한다;
- 어떤 우회도 아직 통과하지 않은 FCL을 `PASS`로 간주하지 않는다.

상세 운영 방법론은
[`HSWM_ADAPTIVE_REALIZATION_METHODOLOGY_2026-08-30.md`](../research/HSWM_ADAPTIVE_REALIZATION_METHODOLOGY_2026-08-30.md)에 둔다.
