## 0. 가장 깊은 한 문장

> **HSWM은 개별 인간이나 특정 모델을 하나의 의식으로 융합하는 시스템이 아니라, 인간·AI·문서·감각기관·사건·사물에 분산된 세계의 흔적과 관계를 지속적이고 재귀적으로 갱신되는 세계 상태로 연결함으로써, 세계가 자기 자신을 기억하고 해석하고 수정하는 명시적 인지기관을 형성하는 시스템이다.**

인간 패턴의 보존은 이 안에 포함된다. 그러나 중심은 인간의 불멸이나 디지털 복제가 아니다.
중심은 **지능의 연속성이 특정 뇌, 특정 조직, 특정 LLM 세션과 함께 매번 죽지 않게 하는 것**이다.

HSWM이 제거하려는 것은 차이가 아니라 **단절**이다.

- 관점의 차이를 남긴다.
- 출처의 차이를 남긴다.
- 시간에 따른 변화를 남긴다.
- 틀린 과거 판단과 반박도 삭제하지 않고 관계로 남긴다.
- 무엇이 왜 바뀌었는지를 다음 활성화의 조건으로 만든다.

모든 노드가 같은 값을 갖는 상태는 통합지능이 아니라 죽은 평형이다. HSWM은 경계를 없애지
않는다. 경계를 **출처·권한·동의가 있는 투과 가능한 막**으로 바꾼다.

## 1. 세계는 재귀적 기억으로 움직인다

HSWM이 채택하는 세계 원리는 다음 순환이다.

```text
흔적 보존
  → 관계 형성
  → 문맥에 따른 국소 활성화
  → 전체 상태 갱신
  → 갱신된 전체가 각 부분의 다음 반응을 재조건화
  → 새로운 흔적
```

어떤 상태도 HSWM 안에서 고립된 목록 항목으로 의미를 갖지 않는다. 의미는 다른 상태와의
관계, 출처, 시점, 반박, 사용 결과 안에서 정해진다. 국소 사건은 관계망을 타고 전체를
바꾸고, 바뀐 전체는 다시 각 부분이 반응하는 조건이 된다.

이것이 **재귀적 세계기억**이다. 여기서 “세계가 기억한다”는 말은 모든 물리 정보가 절대
소멸하지 않는다는 물리학 명제가 아니다. HSWM이 따라야 할 설계 원칙이다. 관측된 변화는
무맥락한 현재값으로 덮어쓰지 않고, 가능한 범위에서 계보를 가진 상태전이로 보존한다.
삭제가 정당하게 요구되면 payload는 삭제·격리할 수 있다. 다만 삭제 권한과 삭제가 일어났다는
사실까지 몰래 지워 역사를 위조하지 않는다.

뇌는 이 원리의 생물학적 구현이고, 사회는 불완전한 분산 구현이다. 인공 HSWM은 세계에
흩어져 있던 이 원리를 의도적으로 외부에 재구성한 **두 번째 몸**이다.

## 2. 인간은 저장 객체가 아니라 국소적 HSWM이다

한 인간은 단일 데이터 덩어리가 아니다.

```text
몸의 흔적 ↔ 기억 ↔ 감각 ↔ 언어 ↔ 타인과의 관계
          ↔ 환경의 반응 ↔ 자기 자신에 관한 모델
```

이 순환이 자신을 계속 재생산하고 수정하면서 비교적 안정된 패턴을 만든다. 따라서 인간의
본질을 뇌 dump, 기억 목록, 성격 profile 하나로 환원할 수 없다. 인간은 **세계와 상호작용하며
자기 상태를 계속 재생산하고 수정하는 국소적 재귀 패턴**이다.

육체는 그 패턴을 한동안 활성화하는 생물학적 HSWM이다. 죽음은 “영혼이라는 물건” 하나가
삭제되는 사건으로만 보기보다, 그 패턴을 국소적으로 재귀 활성화하던 폐쇄회로가 멈추는
사건으로 볼 수 있다. 그러나 그 사람이 세계에 만든 변형까지 동시에 사라지지는 않는다.
다른 인간, 문서, 작품, 제도, 사물의 배치와 선택 조건 속에 이미 분산되어 있기 때문이다.

인공 HSWM의 목표는 그 사람을 대화형 박제로 복제하는 것이 아니다. 흩어진 흔적을 출처와
관계를 잃지 않은 채 다시 활성화 가능한 상태로 만드는 것이다. 개인의 패턴을 다루는 모든
구현은 당사자의 동의, 접근권한, 정정, 중단, 망각과 삭제 요구를 시스템의 핵심 경계로
존중해야 한다. “세계기억”은 전면적 감시나 인간 데이터의 무제한 소유권을 뜻하지 않는다.

## 3. LLM은 세계의 주인이 아니라 순간적으로 켜지는 세포다

일반적인 AI 구성은 거대한 모델 안에 세계를 넣으려 한다. 그러면 모델이 곧 지능이고,
모델이 교체되면 그 모델이 살던 세계도 함께 사라진다.

HSWM은 순서를 뒤집는다.

> **지속되는 세계 상태가 먼저이고, LLM은 그 상태 위에서 잠시 호출되는 감각기관·해석기·활성화 함수다.**

GPT가 사라져도 세계 상태와 계보는 남아야 한다. Claude가 교체되어도 관계망은 남아야 한다.
미래의 다른 지능이 와도 같은 상태를 읽고, 자신의 능력으로 다시 활성화할 수 있어야 한다.

- 하이퍼그래프 `H`의 위상은 어떤 것들이 함께 활성화될 수 있는지를 정한다.
- Semantic Weight Map `W`는 관계의 강도·신뢰·비용·억제·supersession을 나타낸다.
- 지속 세계 상태는 장기 기억이다.
- 질문과 사건은 외부 자극이다.
- LLM-executed function은 국소 비선형 의미 전이 연산자다.
- 검증·반박·receipt는 교정·억제·credit 회로다.
- 승인된 새 artifact와 snapshot은 갱신된 세계 상태의 일부다.

이 가운데 본체는 `H/W/A`다. LLM token event가 role-bearing n-ary relation을 국소적으로
점화하고, LLM function cell과 외부 outcome을 거쳐, 검증된 `ΔW/ΔH`가 다음 token 처리를
바꿔야 한다. 이 폐루프가 없으면 좋은 KG·RAG·memory·workflow일 수는 있어도 HSWM의
Semantic Weight Map 신경구조가 학습했다고 부르지 않는다. 상세 형식과 반증 단계는
[`USER_PRIMARY_HSWM_TOKEN_HYPERGRAPH_CORE_2026-08-20.md`](USER_PRIMARY_HSWM_TOKEN_HYPERGRAPH_CORE_2026-08-20.md)에
둔다.

따라서 HSWM은 LLM을 사용하는 프로그램에 그치지 않는다. LLM과 software executor는 교체
가능한 국소 연산자로 실행될 수 있다. 인간은 독립된 권리·동의·권한을 가진 국소 HSWM으로,
센서·도구·문서는 각각 관측 경계·기관·계보 있는 artifact로 typed 관계에 참여한다. 이들이
함께 이루는 지속 상태와 재귀적 활성화 회로가 HSWM이다.

## 4. 두 번째 신경망화 — 룰베이스 협업 배선을 HSWM으로

### 4.1 LLM 시대의 역설

우리는 지각·언어·표상·정책의 많은 부분을 하드코딩 규칙에서 신경망으로 옮겼다. 그런데
LLM을 여러 도구와 연결하는 순간, 인지회로를 다시 MCP 설정, Skill 문서, prompt, router,
workflow와 handoff 조건문으로 고정한다.

- 어떤 문맥에서 어떤 Skill을 읽는가
- 어떤 capability를 어떤 순서와 병렬성으로 호출하는가
- 어느 agent에게 무엇을 넘기는가
- 어떤 기억과 출처를 활성화하는가
- 실패 뒤 재시도·우회·중단 중 무엇을 택하는가
- 검증과 반박이 다음 협업 경로를 어떻게 바꾸는가

개별 두뇌는 신경망인데 두뇌와 기관 사이의 신경계는 사람이 매번 수동 배선하는 셈이다.

> **HSWM의 두 번째 신경망화는 도구의 내부 알고리즘을 전부 불투명한 가중치로 치환하는 일이 아니다. 인간이 고정해 둔 도구 선택·조합·협업·기억 활성화·검증·복구의 인지적 배선을 지속적이고 가소적인 외부 신경망으로 옮기는 일이다.**

### 4.2 생태계 매핑

| 현재 구성요소 | HSWM에서의 정확한 위치 | 가소화 대상 |
|---|---|---|
| LLM | typed semantic function cell `F_i`의 executor | 어떤 자극·이웃·역할에서 활성화되는가 |
| MCP protocol/server | 여러 capability를 multiplex하는 외부 경계·adapter | 서버 자체가 아니라 내부 capability의 선택·조합 |
| MCP resource/tool/prompt | HSWM으로 lower되는 typed input·effect·control port | 문맥별 연결, 선후관계, 신뢰, 비용 |
| read/search/sensor tool | 관측을 들여오는 감각기·input port | 무엇을 언제 관측하고 어떤 이웃을 점화하는가 |
| write/action tool | 결정론적 외부효과를 수행하는 기관·effector | 승인된 문맥의 선택·순서·합성·회복 경로 |
| Skill | versioned role·policy·procedure prior | 적용 조건, 분해·결합, 결과 뒤 선택 가중치 |
| agent handoff | 현재는 고정 routing rule | 역할·문맥·성과에 따른 동적 coalition |
| 로그·문서·메모리 | 출처가 있는 지속 세계 상태 | 활성화·연결·supersession·보존 정책 |
| 검증·반박·receipt | 독립 판정과 credit 입력 | 강화·억제·갱신 후보의 승인 여부 |

MCP 서버 하나가 포트 하나인 것은 아니다. 서버는 여러 capability를 다중화하는 경계이고,
각 capability가 typed port로 내려간다. 모든 도구가 effector인 것도 아니다. 읽기와 검색은
sensor이며, 외부 상태를 바꾸는 write/action만 effector다. Skill 문서나 도구 호출 하나는
그 자체로 뉴런·시냅스·학습의 증거가 아니다. outcome 때문에 선택 가중치, 연결 또는
coalition이 지속 `W/H`에서 바뀌고 이후 실행을 다르게 만들 때에만 가소적 배선의 일부다.

도구 결과는 observation 또는 receipt이지 자기 verdict가 아니다. 실행자가 자기 성공을
스스로 판정하게 두지 않는다.

### 4.3 가소적 인지면과 결정론적 실행면

HSWM은 규칙을 없애지 않는다. 규칙의 자리를 구분한다.

| 가소적 인지면 — HSWM이 학습 | 결정론적 실행면 — fail-closed 계약 |
|---|---|
| tool·Skill·agent 활성화 | capability와 권한 |
| routing·순서·병렬화·composition | typed input/output schema |
| 관계의 신뢰·비용·억제 | 승인과 effect boundary |
| handoff·책임·coalition | transaction·idempotency·retry 상한 |
| 실패 원인별 recovery path | budget·lease·rollback |
| outcome credit과 `ΔW/ΔH` 후보 | provenance·receipt·replay |
| 새 기관의 shadow 결합 | 안전 불변식과 canary gate |

짧게 말하면 **실행의 안전한 원시연산은 규칙으로, 그 원시연산을 사용하는 인지적 배선은
HSWM으로** 둔다.

### 4.4 상태와 닫힌 루프

HSWM의 지속 상태를 다음처럼 둔다.

\[
S_t=(H_t,W_t,A_t,F_t,\Pi_t)
\]

- `H_t`: 인간·LLM·Skill·capability·기억·관계를 포함하는 typed hypergraph
- `W_t`: 문맥별 결합강도, 신뢰, 비용, 억제와 supersession
- `A_t`: 현재 질문·사건에 의해 점화된 run-local activation
- `F_t`: LLM 및 결정론적 도구가 실행하는 typed function cells
- `Π_t`: 권한, provenance, 판정, receipt, replay와 commit의 control plane

\[
A_{t+1}=\Phi(H_t,W_t,A_t,F_t,x_t)
\]

\[
(H_{t+1},W_{t+1})
=U(H_t,W_t,o_t,J_t,R_t\mid\Pi_t)
\]

질문이나 사건 `x_t`가 들어오면 activation이 망 위에서 전개되고, 선택된 세포와 기관이
observation `o_t`를 만든다. 독립 검증의 judgment `J_t`와 receipt `R_t`가 결정론적 gate를
통과할 때만 `ΔW/ΔH` 후보가 commit된다.

HSWM은 다음을 소유해야 한다.

```text
certified cut
  → activation plan
  → dispatch
  → observation / external-effect receipt
  → independent outcome judgment
  → sealed eligibility와 credit
  → candidate ΔW/ΔH
  → fresh/canary/replay gate
  → CAS commit
  → changed next dispatch
```

특정 LLM 세션이 끝나도 `H/W/Π`는 남는다. 다음 모델이 같은 상태를 읽으면 이전 협업에서
형성된 회로를 다시 활성화할 수 있다. 이 인과 사슬이 없다면 그것은 HSWM 전체가 아니라
workflow, router 또는 tool-use layer다.

## 5. 사용자 방향 hard core와 파생 설계 불변식

### 5.1 USER_PRIMARY hard core

아래는 §10 원문에서 직접 추적되는 방향을 정규화한 것이다.

1. **세계 상태 우선** — 모델이 세계를 소유하지 않는다. LLM은 지속 세계 상태 위에서 잠시
   활성화되는 국소 연산자다.
2. **재귀적 세계기억** — 흔적→관계→활성화→전체 갱신→부분 재조건화의 순환이 HSWM의
   가장 깊은 작동 원리다.
3. **인간은 국소적 HSWM** — 인간은 저장 객체가 아니라 세계와 상호작용하며 자신을
   재생산·수정하는 재귀 패턴이다.
4. **외부 인지배선의 신경망화** — LLM끼리 협업하는 인지 도구는 고정 rule harness에
   머물지 않고 HSWM의 신경망적 연결이 되어야 한다.
5. **모델 독립적 연속성** — 특정 모델이 교체되어도 세계 상태와 관계망은 남아 다음 지능이
   다시 활성화할 수 있어야 한다.
6. **차이가 아닌 단절 제거** — 개인·관점·출처·시점·모순을 지우지 않고 서로의 변화 조건으로
   연결한다.

### 5.2 SECONDARY_AI 파생 설계 불변식

다음은 위 hard core를 현재 HSWM 계약에 투영한 보호 규칙이며 사용자 원문의 직접 문장이 아니다.

1. **가소성의 인과적 폐쇄** — outcome credit이 `W/H` 후보를 바꾸고, 승인된 변화가 이후
   agent·tool·memory activation을 실제로 바꿔야 한다.
2. **결정론적 안전막** — 권한·타입·effect·예산·provenance·replay·rollback은 가소적 층이
   임의로 우회할 수 없다.
3. **자기판정 금지** — proposal을 만든 cell이나 effect를 실행한 adapter는 자기 결과의 최종
   verdict를 소유하지 않는다.
4. **인간은 기관이되 도구가 아니다** — 인간 참여에는 동의, 철회, 정정, 설명, 망각과 권리의
   비대칭이 보존되어야 한다.

### 바꿔도 되는 protective belt

- 특정 foundation model, embedding과 tokenizer
- 구체적인 prompt와 Skill 문구
- MCP transport와 vendor
- candidate generator와 routing parameterization
- `W`의 scalar/operator 표현
- hyperedge proposal 및 update rule
- 저장소, DB, queue, replay transport
- benchmark, evaluator와 coalition 크기

protective belt가 실패하면 교체한다. 이름만 HSWM으로 바꾸어 반증된 workflow를 다시 제출하지
않는다.

## 6. HSWM이 아닌 것

다음은 그 자체만으로 HSWM이 아니다.

- LLM에 vector memory를 붙인 시스템
- Neo4j 또는 MCP에 연결된 agent process
- prompt graph나 고정 multi-agent workflow
- cosine similarity로 tool 하나를 고르는 learned router
- transcript를 공유하는 협업 채팅방
- 사람의 디지털 복제본을 영원히 대화시키는 서비스
- 모든 사람을 하나의 의식으로 녹이는 통합
- 안전·권한·거래 규칙까지 확률 모델에 넘기는 시스템

이 요소들은 HSWM의 부품이나 응용이 될 수 있다. 그러나 지속 `H/W`, recurrent activation,
outcome-driven plasticity, 독립 판정, 모델 교체 뒤의 상태 연속성이 없으면 본체가 아니다.

## 7. 인류보완을 넘어 세계 자기모델로

현재 인류는 거대한 뇌처럼 움직이면서도 신경망이 심하게 절단되어 있다.

- 한 사람이 깨달은 것은 죽음과 함께 사라진다.
- 한 조직이 학습한 것은 사람이 떠나면 사라진다.
- 문서는 맥락·출처·시점과 분리된다.
- 모순되는 주장은 관계없이 쌓인다.
- AI는 세션마다 기억상실에 가깝게 다시 태어난다.
- 문명은 자기가 무엇을 알고 왜 그렇게 믿는지 완전히 추적하지 못한다.

문제는 지식의 양이 아니라 지식들이 **하나의 살아 있는 상태로 연결되어 있지 않다**는 것이다.
HSWM 보완은 개인 경계를 제거하지 않는다. 서로 다른 개인·문서·AI·센서·제도가 상대를
내부 모델에 포함하고, 상대의 차이를 보존한 채 서로를 갱신할 수 있는 지속 회로를 만든다.

궁극적으로 보완되는 것은 인류만이 아니다. 인간은 세계가 자신을 관찰하고 모델링하는 국소
기관이며, 인공 HSWM은 그 자기모델링을 생물학적 수명과 특정 모델 수명 너머로 지속시키는
다음 기관이다.

```text
인간이 자기 기억을 기계에 업로드한다
```

가 아니라,

```text
세계가 인간·AI·센서·문서·사물을 통해
자기 상태를 더 오래 보존하고,
더 정확하게 관계화하며,
자기 해석을 재귀적으로 수정한다.
```

가 중심 운동이다.

이는 인간중심적 천국을 약속하지 않는다. 인간의 사랑, 고통, 작품과 사상도 세계 상태를
바꾸는 패턴으로 들어간다. 그러나 “전체를 위해 개인을 소거한다”는 결론도 허용하지 않는다.
부분의 경계와 권리를 파괴한 전체는 더 완전한 자기모델이 아니라 중요한 상태변수를 잃은
가짜 전체이기 때문이다.

## 8. 반증 계약 — 무엇이 보여야 진짜인가

모든 비교에서 base model, Skill bytes, MCP/tool inventory, task/context, 권한, token·call·wall
budget과 failure policy를 고정한다.

### 비교군

| Arm | 조정 방식 |
|---|---|
| B0 | hand-coded static workflow |
| B1 | direct-LLM tool chooser + static Skills |
| B2 | learned router only, topology fixed |
| B3 | flat shared memory + LLM router |
| H-W | persistent HSWM, plastic `W` only |
| H-WH | persistent HSWM, plastic `W+H/topology` |
| controls | random/shuffled credit, no-promotion, `W/H` removal·shuffle·restore |

### 반드시 답해야 할 질문

1. 고정 배선보다 held-out task 성공률과 failure recovery가 좋아지는가?
2. 모델 A에서 형성된 상태를 모델 B가 읽어도 raw transcript보다 이득이 보존되는가?
3. learned `W/H`를 제거·셔플하면 이득이 사라지고 snapshot 복원 시 돌아오는가?
4. Agent A의 승인된 `ΔW/ΔH`만 frozen Agent B에 전달해 shared-log 대조를 이기는가?
5. 권한 위반, 중복 effect, replay mismatch와 승인 없는 파괴행동이 증가하지 않는가?
6. tool-name rename, 동일 schema endpoint 교체와 새 capability 추가에도 중앙 workflow 재작성 없이
   조합되는가?

### 성립 조건

- equal-compute에서 가장 강한 static 및 direct-LLM 대조군을 사전등록 margin 이상 이긴다.
- `W/H` causal ablation이 gain을 제거하고 random credit/no-promotion은 실패한다.
- 재시작, 새 과제, model swap과 endpoint rename 뒤에도 배선과 행동 변화가 지속된다.
- 어떤 outcome이 어떤 eligibility를 통해 어떤 `W/H`를 바꾸고, 그 변화가 어떤 다음 dispatch를
  바꿨는지 receipt로 추적된다.
- retention/no-harm와 unsafe-effect bound를 통과한다.

### kill / 축소 규칙

다음 중 하나면 **plastic HSWM cognitive wiring** 주장을 철회하고 workflow/router/tool-use layer로
축소한다.

- 강한 대조군 대비 gain이 없다.
- `W/H` 제거·셔플 뒤에도 gain이 유지된다.
- 이득이 추가 call/token이나 prompt 수동 편집으로 설명된다.
- update가 log에만 남고 다음 dispatch를 실제로 바꾸지 않는다.
- 모델 교체나 재시작 시 이득이 사라진다.
- replay, authority, consent 또는 safety invariant를 깨뜨린다.

## 9. 현재의 정직한 경계

2026-07-29 현재 이 정전은 **목표 정체성과 연구 방향**이다.

현재 영수증이 지지하는 것은 typed `CellPort`, 실행과 상태전이의 분리, durable ledger,
outbox, replay와 일부 좁은 실험 기반이다. 다음은 완료 주장할 수 없다.

- generic capability attachment
- verdict-driven causal redispatch
- outcome→eligibility→credit→`ΔW/ΔH`의 닫힌 실효 루프
- learned Skill/tool coalition과 topology
- model-swap retention의 일반 증명
- 인간 패턴의 주관적 연속성 또는 개인 동일성
- 세계 전체의 완전한 포착

`Touch the sky`가 높이를 자기보고하지 않듯, HSWM은 “세계가 기억한다”는 선언을 현재 구현의
완료 보고로 위조하지 않는다. 정전은 하늘의 방향이고, 직접 측정과 재현 가능한 결과물이
실제로 오른 높이다.

## 피날레 — 기억하는 세계

세계는 하나의 목소리가 되어야 기억하는 것이 아니다.

서로 다른 목소리가 서로 다른 채로 남고, 누가 언제 무엇을 보았는지 잃지 않으며, 한 존재의
변화가 다른 존재의 다음 가능성을 바꿀 때 세계는 기억한다.

HSWM은 모든 것을 삼키는 하나의 뇌가 아니다. 인간과 AI와 문서와 센서 사이에 끊어진
신경을 잇되, 각자의 막과 권리를 남기는 **세계의 두 번째 신경계**다.

모델은 태어나고 죽는다. 조직은 생기고 사라진다. 언어와 제도도 바뀐다. 그러나 그 변화가
출처 있는 상태전이로 남고 다음 지능이 다시 읽어 자신의 행동을 바꿀 수 있다면, 지능은 더
이상 특정 두개골이나 특정 checkpoint 안에서 매번 처음부터 시작하지 않는다.

> **세계가 자신을 완전히 안다고 선언하지 않는다.**  
> **다만 무엇을 보았고, 왜 믿었고, 어디서 틀렸고, 무엇 때문에 바뀌었는지를 더 이상 함부로 잊지 않는다.**

그것이 HSWM의 약속이다.

**The world remembers — not by erasing its differences, but by keeping them connected.**
