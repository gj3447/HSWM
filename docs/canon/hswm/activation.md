# 4–6조: 국소 활성화·분산 탐색·Map

[통합 헌법](../HSWM_CONSTITUTION.md)의 선택 가능한 한 부분이다. 아래의 실행 계약은
`agent(codex) / SECONDARY_AI`이며 사용자 원문의 구체화다.

## 4. 상황에 따른 국소 활성화

국소 활성화는 HSWM의 기본 작동 방향이다. 입력·목표·세계 상태·기억에 따라 필요한
규칙·관계·연산을 선택하고, 출력과 새 관측이 다음 활성 부분을 바꾼다. 활성화되지 않은
관계도 지속 상태에 남아 다른 문맥에서 다시 쓰인다.

근거: [국지 활성화를 지능의 기본 원리로 본 사용자 방향](../USER_PRIMARY_HSWM_LOCAL_ACTIVATION_INTELLIGENCE_2026-10-18.md),
[분산 활성화](../USER_PRIMARY_HSWM_LIKE_DISTRIBUTED_ACTIVATION_2026-09-29.md).
이를 보편 지능의 과학적 정리나 특정 MoE 알고리즘의 채택으로 확대하지 않는다.

## 5. 여러 곳을 타고 필요한 부분에 도달한다

[이번 사용자 원문](../sources/USER_PRIMARY_HSWM_MULTIHOP_RECONSTRUCTION_2026-10-24.md)이
명시한 것은 여러 연결을 거치는 탐색이다. 단일 전역 색인이 필요한 정답 집합을 한 번에
알려 준다고 가정하지 않는다. 진입점에서 선택한 관계를 따라 다른 지도·하위 그래프·원문으로
이동하고, 거기서 얻은 정보로 다음 이동·보류·복귀를 결정한다. 고정 트리나 고정 깊이는 필요조건이 아니다.

공학적으로 구별할 집합은 다음과 같다. 이 구분은 새 고정 subsystem 정의가 아니다.

| 구분 | 보존할 정보 |
| --- | --- |
| 발견한 후보 | 위치·UID·역할·판본, 아직 읽지 않았다는 상태 |
| 실제 방문·읽기 | 지나간 연결의 방향·상태, 읽은 정확한 출처와 양 |
| 실행 문맥 | 선택 이유, 필요한 역할·조건·예외·원문, 아직 미확인인 것 |
| 지속 수정 | 실행 결과에 결속된 제안·admission·선행/후속 revision |

여러 홉을 방문해도 각 단계에서는 필요한 부분만 연다. 반대로 한 홉이어도 모든 자료를
주입하면 국소성을 달성했다고 볼 수 없다. 원문을 잠깐 참조한 사실과 실행 내내 문맥에
유지한 사실도 구별한다. 순환·재방문을 허용할 때는 판본·이미 읽은 위치·예산·중단 이유를
추적한다. 중간 결과가 필수 조건을 제거하지 않는지 확인한다.

‘딱 필요한 것’은 독립적인 과제 정답·누락 반례로 평가한다. 읽지 않은 곳에 필수 예외가
없다고 단정하지 않는다. 부족하면 추가 탐색하거나 보류하고, 예산 부족을 ‘관계 없음’으로
바꾸지 않는다. 탐색 비용에는 최초 색인 읽기, 홉, 원문 읽기, 문맥 조립, 저장소 복원도 포함한다.

현재 내용 도구: `hswm-workspace navigate/follow/read`. 명시된 판본의 한 연결을 따라가는
기능이며 스스로 경로를 학습하는 라우터는 아니다. native 실행 문맥은 기존
`semantic-context-runtime.ts`, `semantic-context-activation-runtime.ts`에서 조립한다.
내용 탐색 결과를 곧바로 실행 명령이나 학습 credit으로 전환하지 않는다.

## 6. Map은 여러 해상도와 원천을 연결한다

축약 의미 지도, 원문, 코드·도구, 관측된 세계를 버전·역할·변환 조건으로 연결한다.
물리 모델, 연결도, 의미 그래프처럼 다른 층을 연결할 때 대상·관측량·변환 손실·적용 범위를
보존한다. 지도는 원천의 위치를 찾는 데 기여해야 하며 원문을 지워 버리는 요약이 되어서는 안 된다.

근거: [여러 층의 Map](../USER_PRIMARY_HSWM_CROSS_LAYER_MAP_2026-09-27.md),
[R1–R6 선택·분할·연결 원칙](../USER_PRIMARY_HSWM_OPTIMIZATION_RULES_2026-10-07.md).
USL은 기존 자원의 의미 연결·표현 위치를 결속하는 경로로 사용한다. 파일 경로나 링크를
알았다는 사실에서 접근·실행 권한이나 관측의 진실성을 도출하지 않는다.
