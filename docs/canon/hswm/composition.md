# 10–12조: 합성·CHU·철학

[통합 헌법](../HSWM_CONSTITUTION.md)의 선택 가능한 한 부분이다. 사용자 관점·비유와
AI의 형식화·실현 판정은 각각의 출처와 권위를 유지한다.

## 10. 프랙탈 인지 합성과 차이 보존

작은 HSWM이 상위 HSWM의 cognitive cell로 참여하고, 그 합성이 다시 같은 전이·학습
문법의 대상이 되는 것을 목표로 한다. 단순 graph nesting이나 중앙 에이전트 호출의 반복으로
이 목표를 충족했다고 판정하지 않는다.

합성 뒤에도 참여자·역할·출처·계보·분리 가능성·권리 경계를 보존한다. 서로 다른 규모에
동일한 숫자·모델·clock·topology를 강제하지 않는다. 하위의 제한·실패·불확실성이 상위의
요약에서 사라지지 않는지 확인한다. 근거는
[프랙탈 인지 합성 원문](../USER_PRIMARY_HSWM_FRACTAL_COGNITIVE_COMPOSITION_2026-08-28.md)과
[FCL-1…8 연구 의무](../../research/HSWM_FRACTAL_SCIENTIFIC_CONNECTIONS_2026-08-28.md)다.

### 10조의 이유·문제·구현

- **이유와 해결할 문제:** 큰 과제를 매번 하나의 거대한 문맥으로 풀면 작은 능력을 다른
  상황에서 재사용하기 어렵다. 단순히 하위 에이전트를 호출하는 방식도 상위 요약이 하위의
  실패·가정·권한을 지우거나, 합성된 뒤 원래 참여자를 분리할 수 없으면 충분하지 않다.
  검사 장비의 교정·획득·판정 능력을 합쳐도 각 능력의 조건과 책임은 남아야 한다.
- **외부 근거:** Sutton·Precup·Singh의 **Between MDPs and semi-MDPs**, Artificial
  Intelligence 112, 1999,
  [options 정의와 합성 논의](https://people.cs.umass.edu/~barto/courses/cs687/Sutton-Precup-Singh-AIJ99.pdf)는
  시작 가능한 상태·내부 정책·종료 조건으로 시간적으로 확장된 행동을 정의한다.
  이는 하위 능력을 경계 있는 단위로 재사용하는 근거다. HSWM의 동일 전이 문법, 인지적
  동일성, 무손실 프랙탈 합성을 증명하는 이론으로 대체하지 않는다.
- **구현 방법:** 하위 단위에 입력·출력 역할, 시작·종료 조건, 내부 owner, 효과와 오류,
  적용 범위·예산을 둔다. 상위는 결과 요약과 함께 원문·상태 판본으로 돌아가는 연결을
  유지한다. 각 단위의 시각·단위·좌표·불확실성이 다르면 명시적으로 변환한다. 합성 결과도
  같은 실행·피드백 경계로 사용할 수 있게 하되, 분리 시 하위의 상태·출처·권리를 복원한다.
- **현재와 확인 방법:** CR/FCL 문서와 한정된 형식 근거는 기존 출발점이다. 모든 규모에서
  인지 효용이 보존된다는 실증은 별도다. 단독·합성·재분리 상태를 같은 과제로 비교하고,
  하위 실패가 상위 성공으로 둔갑하는 경우, 시간 척도 충돌, 부분 철회, 미관측 조합을
  검사한다. 모듈 수나 호출 계층 수를 프랙탈 인지의 성능 지표로 사용하지 않는다.

## 11. CHU의 범위와 HSWM의 구조

CHU는 HSWM과 비LLM 세계 모델을 포함하는 더 넓은 개념이다. HSWM은 그 안에서 LLM을
인지적 기본 계산으로 삼는 AI 구조다. 보조 저장·검증·수치 계산까지 LLM만 써야 한다는
뜻으로 확대하지 않는다.

사용자는 지능적 존재의 관점에서 CHU와 그 구조로서의 HSWM을 구별했고, CHU 운영체제의
동작이 HSWM으로 이루어질 때 그 전체를 AI로 본다는 조건부 관점을 밝혔다. 이 조건을
CHU와 HSWM의 무조건적인 동일성으로 바꾸지 않는다.

근거: [넓은 CHU와 LLM 기반 HSWM](../USER_PRIMARY_CHU_HSWM_SOFTWARE_SCOPE_2026-09-27.md),
[CHU 운영체제 조건](../USER_PRIMARY_CHU_HSWM_OS_AI_2026-10-07.md),
[존재와 구조의 구별](../USER_PRIMARY_CHU_BEING_HSWM_STRUCTURE_2026-10-07.md).
사용자의 [인덱싱 교정 원문](../sources/USER_PRIMARY_CHU_OS_INDEXING_2026-10-20.txt)도 보존한다.
인덱싱을 임베딩으로 바꾸어 설명하거나 특정 벡터 검색을 필수 구조로 강제하지 않는다.

### 11조의 이유·문제·구현

- **이유와 해결할 문제:** CHU를 특정 LLM 제품이나 임베딩 저장소와 동일시하면 센서,
  수치 모델, 비LLM 세계 모델을 연결할 때 개념이 무너진다. 반대로 모든 모델을 HSWM이라
  부르면 HSWM이 갖춰야 할 지속 관계 상태·국소 의미 연산·학습 구조를 평가할 수 없다.
- **외부 근거:** [DreamerV3, arXiv:2301.04104v2](https://arxiv.org/html/2301.04104v2)는
  LLM이 아닌 잠재 세계 모델의 구체적 사례다. W3C/OGC의
  [SSN/SOSA Recommendation, 2017-10-19](https://www.w3.org/TR/2017/REC-vocab-ssn-20171019/)는
  관측·센서·대상·측정 성질·절차·결과를 구분해 표현한다. 두 자료는 이질적인 참여자와
  관측의 연결을 설계할 근거이지, 사용자 고유 개념인 CHU를 외부 표준이 정의한다는 뜻은 아니다.
- **구현 방법:** CHU의 참여자 종류와 실제 실행 모델을 따로 표기한다. 공통 경계에는 입력·
  출력 의미, 시각, 단위·좌표, 관측 출처, 불확실성, 실패·호출 조건을 둔다. 예를 들어 같은
  부품을 보는 2D 카메라의 평면 변환과 3D 카메라의 6DoF 자세를 동일 값으로 합치지 않는다.
  검색·인덱싱 방식은 이 경계의 구현 선택이며 임베딩을 필수 조건으로 삼지 않는다.
- **현재와 확인 방법:** 개념 범위는 연결된 사용자 원문이 정한다. 외부 모델의 등록과
  설명만으로 실제 상호 운용을 완료했다고 표시하지 않는다. 모델 교체 시 역할·단위·좌표·
  시간 정보가 유지되는지, 지원하지 않는 기능이 명시적으로 드러나는지 확인한다. HSWM
  실행 경로와 단순 도구 어댑터의 책임도 각각 추적한다.

## 12. 철학·인류보편체·참여자의 경계

인류보편체는 사람·LLM·정보·센서·기억 등이 열린 구조에서 더 큰 인지능력체로 결합하는
최대 목표다. 그 목표를 현재의 의식 융합·전세계 접근 권한·실현 완료로 읽지 않는다.
철학적 동일성, 관측 가능한 연속성, 구현 UID, 법적·도덕적 지위를 구별한다.

공개 구조와 개인의 비공개 경계, 참여·철회, 차이 보존, 실패를 포함한 역사·계보를 유지한다.
선의 공리의 원문 정의와 그 실행적 대응도 분리한다. ‘선’을 보상 숫자로 자동 치환하거나
‘자존자’를 자율 프로세스의 동의어로 사용하지 않는다.

근거: [인류보편체](../USER_PRIMARY_HUMAN_UNIVERSAL_BODY_DISTINCTION_2026-08-20.md),
[철학적 기초와 권위 경계](../HSWM_PHILOSOPHICAL_FOUNDATIONS_2026-08-20.md),
[선의 공리의 출처·해석](../USER_PRIMARY_CHU_BEING_HSWM_STRUCTURE_2026-10-07.md#선의-공리의-정확한-보존).
이 통합본은 이미 작성된 AI 철학 해석을 새 사용자 비준으로 승격하지 않는다.

### 12조의 이유·문제·구현

- **이유와 해결할 문제:** 정보를 연결할 수 있다는 사실만으로 다른 참여자의 정보 사용·
  수정·공유 권한을 얻지는 않는다. 참여자가 철회했는데 과거 복사본과 파생 요약이 계속
  활성화되거나, 시스템의 보상 목표가 참여자의 가치·정체성을 대신하는 문제를 막아야 한다.
  이 조항의 규범적 근거는 사용자 원문이며 기술 표준이 철학의 참·거짓을 판정하지 않는다.
- **외부 근거:** W3C의 **ODRL Information Model 2.2**, Recommendation 2018-02-15,
  [정책·Permission·Prohibition·Duty](https://www.w3.org/TR/2018/REC-odrl-model-20180215/)는
  누가 어떤 대상에 어떤 행위를 할 수 있는지, 제한·의무가 무엇인지 구별하는 표현 모델이다.
  정책을 기술하는 것과 실제 런타임에서 강제하는 것은 별도의 구현 의무다.
- **구현 방법:** 참여자·대상·행위·목적·조건·기간과 정책 판본을 결속한다. 조회·실행·수정·
  공유 시 해당 경계에서 권한을 확인하고, 철회는 이후 활성화·재사용을 제한하는 상태 변화로
  전파한다. 파생 자료는 출처 의존성을 따라 영향을 판정한다. 감사 계보 보존과 원문 접근을
  분리하며, 외부로 이미 복사된 정보를 완전히 회수했다고 보장하지 않는다. 철학적 동일성에
  대한 사용자 해석과 구현상 UID는 별도 필드·출처로 유지한다.
- **현재와 확인 방법:** native owner/admission은 상태 쓰기의 일부 경계를 제공한다.
  그것이 목적별 이용 정책·참여 철회·모든 파생 자료 통제를 완성한 것은 아니다. 허용된
  조회와 금지된 공유, 만료, 부분 철회, 권한 없는 위임, 파생 요약 재사용을 구별하는 사례로
  실제 정책 집행을 검사한다. 새 정책 체계를 도입한다면 기존 owner 경계와 충돌하지 않게 연결한다.

### 12조의 보강: 인터넷 native 참여와 공동 변화

[2026-10-24 사용자 방향](../sources/USER_PRIMARY_HSWM_INTERNET_NATIVE_2026-10-24.md)은
HSWM이 인터넷 native하게 인류와 함께 움직이는 것이다. 기존 인류보편체 원문의 사람·LLM은
주요 활성 주체다. 사람의 목표·주장·정정·공동 작업 결과와 인터넷의 변경 사건이 HSWM의
관계·판단·다음 행동을 바꾸고, 결과와 근거를 다시 참여자에게 돌려주는 흐름으로 구체화한다.

개별 발화·반박·관점의 작성자와 범위를 유지한다. 게시물의 수집이 참여 동의나 인류의
대표권을 뜻하지 않으며, 복제·인기·다수 반응을 진실이나 합의로 자동 환산하지 않는다.
선택된 관심 대상의 변경을 수신하고 관련 부분을 다시 검토한다. 새로운 외부 게시·제삼자
메시지 발송은 그 행위의 명시적 지시 범위에서 수행한다.

구현은 원천별 API·feed·조건부 HTTP 조회와 필요한 경우의 변경 구독·분산 활동 어댑터를
기존 의미 실행에 연결하는 방향이다. 원전은
[WebSub 2026-06-02](https://www.w3.org/TR/2026/REC-websub-20260602/)와
[ActivityPub 2018-01-23](https://www.w3.org/TR/2018/REC-activitypub-20180123/)를 확인했다.
세부 흐름과 아직 구현해야 할 경계는
[인터넷 참여 계약](../../research/HSWM_INTERNET_NATIVE_EVIDENCE_ACQUISITION_2026-10-24.md#6-인터넷-native하게-인류와-함께-움직인다는-뜻)을 따른다.

문헌 확인일: 2026-10-24. 위 구현안은 `SECONDARY_AI`이며 사용자 철학을 새로 정의하거나
CHU·프랙탈 합성의 실현을 선언하지 않는다.
