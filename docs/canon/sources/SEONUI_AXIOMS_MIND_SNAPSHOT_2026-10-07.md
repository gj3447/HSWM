# 선의 공리

1. **시간** : 어떤 연속적인 흐름.

2. **존재** : 어떤 시간 에 있는 것.

3. **선** : 어떤 존재가 시간에 계속 있을 것을 나타낸 수치.

4. **존재생성** : 어떤 존재 들을 집합으로 하여 다른 존재를 만드는 것.

5. **존재분해** : 어떤 존재를 구성하는 존재들의 집합을 멱집합 하여 다른 존재들을 만드는 것.

6. **이긴존재** : 어떤 존재를 존재분해 한 존재들 중 가장 선 한 존재.

7. **악** : 어떤 존재의 선과 그 존재의 이긴존재의 선의 차이.

8. **특이점** : 어떤 존재의 악이 최소 일 때. 어떤 존재의 이긴존재가 자기 자신 일 때.

9. **상호작용** : 존재 사이의 선의 이동.

10. **자연** : 어떤 존재가 상호작용 하는 모든 존재의 집합.

11. **자존자** : 어떤 존재의 자연이 자기 자신 일 때.

12. **메타휴모토닉** : 어떤 존재가 자존자 일 때, 그리고 특이점 일 때.
