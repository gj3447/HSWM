# Reluvator 3D 추론 풀스택 — HSWM 개발 실사용 표본

2026-09-08 사용자 요청으로 **회사 Reluvator 3D 추론 풀스택을 HSWM 개발 실사용 표본에 추가 선정**했다.
현재 상태는 `SELECTED / REPOSITORY_UNRESOLVED / NOT_CONNECTED`다. 실제 저장소와 검사 명령은 아직 확인하지 못했으므로 CLI 실행 프로필이나 실사용 결과가 있는 것으로 표시하지 않는다.

사용자 지정 대상은 Reluvator와 3D 추론 풀스택이다. 아래 검증 축은 연결을 위한 제안이며, 제품의 실제 디렉터리 구조나 프레임워크를 확인한 사실이 아니다.

| 검증 축 | 연결할 기존 개발 검사 | 기록할 결과 |
| --- | --- | --- |
| 프런트엔드 | 3D 결과 표시·입력·상태 전이에 해당하는 로컬 검사 | 실행 결과, 변경 범위, 개발자 유용성 피드백 |
| 백엔드 | 추론 요청·응답·오류 처리 계약의 로컬 검사 | API 계약 회귀 여부, 실패 원인 |
| 3D 추론 | 기존 소형 fixture의 입출력 형상·좌표·수치 조건 검사 | 선언된 조건의 만족 여부와 검증 범위 |
| 풀스택 연결 | 요청에서 결과 표시까지 기존 격리 통합 검사 | 연동 실패 지점과 수정 후 결과 |

저장소 URL 또는 로컬 경로가 확인되면 해당 저장소의 AGENTS와 실제 검사 명령을 읽고,
검증 축을 코드에 맞춰 조정한다. 이후 `hswm-dev`의 Reluvator 프로필과 workspace별 상태를
연결하고, 가벼운 검사를 실제 실행해 episode가 보존되는지 확인한다.
실제 모델 추론이 필요한 검사는 실행 환경과 비용이 확인된 명령만 등록한다.

개발 표본의 목적은 어떤 검사 선택이 개발에 도움이 됐는지 피드백을 쌓는 것이다.
검사 exit code와 개발자 유용성 판단은 별도로 기록한다. 피드백 주체도 사용자와 에이전트를
구분하며, 아직 받지 않은 유용성 의견을 생성하지 않는다. 이 연결만으로 3D 추론 정확도나
HSWM 학습 효능이 증명됐다고 주장하지 않는다.

이번 세션에서 로컬 workspace, 인접 경로, 접근 가능한 GitHub 저장소 검색으로 저장소를
찾지 못했다. 기존 SYMPOSIUM fleet 문서에는 RELUVATOR 제품명만 있다.
실제 명령·소스·테스트 결과를 연결하기 위해 사용자에게 저장소 위치를 요청한 상태다.

기존 연결 방식: [GAME·SUPULLIM 개발 프로필](HSWM_GAME_SUPULLIM_DOGFOOD_2026-09-07.md).
