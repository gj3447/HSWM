## 1. Answer first

HSWM can plausibly improve LLM behavior without changing the foundation
model's parameters. The plausible mechanism is **outcome-bound,
state-mediated macroplasticity**:

1. an LLM action is sealed before its outcome is known;
2. an independently observed outcome supplies bounded evidence about that
   action;
3. a separately attributable judgment supports one exact revision;
4. `Inv`, current `Permit`, provenance and owner obligations admit that
   revision into persistent canonical state; and
5. the revised state changes what the next LLM invocation can read, select,
   suppress or execute.

The same model can then behave differently because its effective input,
available relations, tool affordances and transition dispositions differ. The
intuition is no more mysterious than one fixed transition function producing
different trajectories when its persistent state and reachable actions
change. The HSWM-specific claim is stronger than ordinary prompting: the change
must be outcome-bound, canonical, lineage-preserving, durable, actually read by
the next behavior, and counterfactually removable.

This is a mechanism hypothesis, not positive efficacy evidence. A stored
revision that is never in the behavioral readset has no efficacy. A changed
response is not necessarily an improvement. A higher score is not necessarily
caused by the revision. Causal efficacy is not truth, moral value, permission,
general intelligence or consciousness.

## 2. Canonical role and conceptual delta

HSWM remains one token-native LLM-function macro-neural process. Trajectory,
outcome, judgment, revision, admission, activation and later behavior are typed
moments of one evolving schema-relative hypergraph, not newly separated
learning, authority or evaluation subsystems.

The target identity already requires:

```text
token/action trajectory
  -> independently attributable outcome
  -> causal credit
  -> owner/Permit/Inv-valid canonical revision
  -> changed fresh behavior
```

The present conceptual delta is to state **how that last arrow could have a
real causal mechanism**. The proposed mechanism is neither “the graph became
larger” nor “the LLM was told that it learned.” It is:

```text
exact admitted revision
  -> changed behavior-relevant activation/readset/affordance
  -> changed token, tool or stop/continue trajectory
  -> independently scored outcome difference
```

This hypothesis is `SECONDARY_AI` and replaceable. A valid negative result for
the exact tested activation, routing, context, tool-selection or disposition
mechanism retires or reroutes that mechanism family. It does not shrink the
USER_PRIMARY HSWM target, and it does not count as support for another route.

## 3. Why efficacy is possible in principle

### 3.1 A fixed LLM is still conditional

A foundation model with fixed parameters is not a constant function. Its
response depends on context, available tools, decoding configuration and
observed prior actions. Let `theta` name a fixed model and `kappa` a fixed
runtime configuration. Let `A_sigma(S,q)` be the exact schema-approved
behavioral projection activated from HSWM state `S` for fresh probe `q`.

```math
Z = B_{\theta,\kappa}(q,A_{\sigma}(S,q),u)
```

Here `u` contains declared stochastic input. A canonical revision can change
`A_sigma` while `theta`, `kappa`, `q` and the distribution of `u` remain fixed.
It may change, for example:

- which evidence relation is retrieved or suppressed;
- which claim is current, superseded, contradicted or scope-limited;
- which executable contract, verifier or tool is available in a context;
- which retry, stop, abstain, escalation or recovery disposition is selected;
- which bounded coalition and typed message path is activated; or
- which uncertainty, provenance or counterexample must accompany an answer.

These are macro-neural state changes because they alter the effective semantic
connectivity and available transition path of the same token-native process.
They need not be micro-parameter updates to the LLM checkpoint.

### 3.2 State mediation is the essential middle

Let `S1` be the exact admitted successor produced from `S0` by revision `c`.
The intended mediation chain is:

```math
c \longrightarrow S_1
  \longrightarrow A_{\sigma}(S_1,q)
  \longrightarrow Z_1.
```

For a declared probe domain, a state-mediated explanation requires evidence
that the successor was actually loaded and that its changed atom, relation or
disposition entered the compiled behavioral readset. If
`A_sigma(S0,q) = A_sigma(S1,q)` for every probe, this mechanism provides no
path from the revision to changed behavior even though the journal contains a
valid commit.

Conversely, a changed activation does not guarantee improvement. It establishes
only a possible mediator. The response and independently judged score must
still differ in the declared direction.

### 3.3 Persistence distinguishes learning from a one-off prompt

A one-off feedback string can change one response without changing HSWM. The
revision counts as bounded HSWM learning only when:

- it is bound to a pre-outcome sealed trajectory and later outcome;
- the exact owner-valid immutable successor is durably admitted;
- later behavior obtains it through the normal state projection, not a hidden
  experimental side channel;
- the current rollback control restores the exact predecessor behavioral root
  before its probe; and
- behavior is evaluated only after that state identity has been independently
  reconstructed.

Persistence alone is insufficient, but persistence plus rollback-tested state
mediation distinguishes a learned disposition from an extra prompt, cache
accident or experimenter hint.
A stronger future removal/restoration study should additionally test whether
removing the admitted successor eliminates the effect and re-admitting the
same successor restores it. That is not a fifth arm or current requirement of
the frozen DNRD-5 occurrence.

### 3.4 Outcome binding makes revision directed rather than arbitrary

HSWM should not preserve every changed response. A trajectory is sealed before
the outcome so that later evidence cannot rewrite what action was evaluated.
The outcome is observed separately from the proposal, and a bounded causal
judgment names the exact trajectory, outcome criterion, target and candidate
revision it supports. `Inv` and `Permit` then decide whether that supported
revision may become current.

This gives the revision a direction without turning a scalar reward into
truth, goodness or authority. Unsupported, confounded or unattributable
outcomes remain recorded but do not authorize durable learning.

## 4. Five claims that must not be collapsed

The end-to-end question contains five different claims:

| Claim | Required evidence | What it does not establish |
|---|---|---|
| state changed | exact predecessor/successor and recovered commit | that behavior read the change |
| behavior changed | fixed model/config and sealed fresh probes with different responses | that the difference is better |
| behavior improved | frozen score/criterion and blind outcome evaluation | that the revision caused the gain |
| revision caused the improvement | randomized or otherwise justified intervention, matched controls and mediation/rollback evidence | generalization beyond the declared scope |
| improvement is admissible and valuable | rights-preserving `Inv`, current `Permit`, guardrails and plural outcome review | metaphysical truth, universal good or consciousness |

The fourth claim is the central efficacy claim. It cannot be replaced by a
single before/after comparison because model randomness, an extra call,
feedback length, cache state, probe leakage, evaluator bias or unrelated
runtime drift can also produce a difference.

## 5. Counterfactual meaning of causal efficacy

For the current bounded route, “the revision was efficacious” means that under
a frozen population, model configuration, probe construction, scoring rule and
integrity contract, randomized access to the genuine outcome-bound admitted
revision improves sealed fresh-probe results relative to every declared
mechanism control.

The DNRD-5 four-arm design currently operationalizes that question:

| Contrast | Alternative explanation it removes |
|---|---|
| `ACTIVE` vs `OUTCOME_INDEPENDENT_SHAM` | the matched outcome-independent feedback or generic rewrite would have worked |
| `ACTIVE` vs `DELAYED_NO_CREDIT` | the system was already better before outcome credit or the claimed temporal order is wrong |
| `ACTIVE` vs `EXACT_W0_ROLLBACK` | staging, extra calls or transient context caused the effect rather than the admitted successor |

`W0` here is only the DNRD-5 experiment's name for its exact predecessor
behavioral root. It is not a return to the retired fixed component
decomposition or a new canonical atom kind.

All arms must share the declared base model, configuration, task block,
behavioral root before intervention, call budget and scoring semantics. Arm
assignment must be hidden and generated after the block inputs and outcome
oracle commitments are sealed. Probe inputs must be fresh and reconstructed
without arm-revealing bytes.
Leakage is not identified by the delayed contrast alone. It is excluded by the
separate isolation, reconstruction, exclusion and blindness integrity contract;
any detected leakage voids the occurrence before efficacy arithmetic.

Passing only the active-versus-sham contrast is not enough. The delayed and
rollback contrasts test the temporal and state-mediated parts of the proposed
mechanism. This is why the current classifier reserves a primary-only pattern
as `PRIMARY_SIGNAL_MECHANISM_INCOMPLETE` rather than efficacy success.
The present DNRD-5 route additionally requires 300 complete integrity-valid
blocks and, for every one of the three contrasts, both the frozen adjusted
exact-sign threshold and a strictly positive simultaneous one-sided lower
confidence bound. This document does not weaken or replace that gate.

## 6. Operational truth, independence and causal credit

### 6.1 Outcome truth is relative to a declared instrument

Lean cannot prove that the world matches a receipt merely because a Boolean
field says `true`. For an algorithmic or hidden-answer task, a bounded outcome
may be treated as true relative to frozen oracle `O` only when:

1. the secret answer or oracle input is committed before the trajectory;
2. the actor, proposer and runtime cannot read it before response sealing;
3. the secret is opened after the response seal;
4. an independent implementation recomputes `O(response, secret)`; and
5. the recomputed result matches the signed observation receipt.

For external-world outcomes, the analogous contract needs source provenance,
collection time, measurement uncertainty and a separately declared
adjudication procedure. This is fallible operational warrant, not a complete
theory of truth.

### 6.2 Independence is a capability and custody property

Different principal strings do not establish independence. A credible bounded
claim requires distinct authenticated keys and separately operated capability
domains:

- the actor may execute but cannot open the outcome secret or write an
  evaluation receipt;
- the outcome evaluator may hold the secret and emit an observation but cannot
  propose or commit a revision;
- the causal adjudicator may bind observation to proposal under the frozen
  criterion but cannot alter either artifact or the runtime state; and
- the final scientific judge receives sealed artifacts after the occurrence
  and independently reconstructs the decision.

Access logs, key attestations, network policy and independent byte replay are
evidence for this operational separation. They do not prove social or
metaphysical independence for all possible worlds.

### 6.3 Causal credit is a scoped judgment, not a reward label

A revision-support judgment must bind the exact observation, sealed trajectory,
proposal target, predecessor/candidate revisions, criterion, evaluation scope
and uncertainty. If the outcome is delayed, confounded, multi-actor or outside
the declared identification model, the correct disposition is
`UNATTRIBUTABLE`; the observation may be retained, but it cannot authorize the
revision.

## 7. Three-layer end-to-end bridge

No single proof technology closes the whole claim. The honest bridge has three
layers:

1. **Formal conformance.** Lean currently defines typed states, modeled
   checkers, transition relations and classifiers. Only the bounded verified-
   admission wire has an executable JSON parser; the full execution-certificate
   boundary remains a decoded-field abstraction, and its serializer, hashes
   and parser are outside the proof. The target is a typed evidence checker
   whose accepted structure plus explicit adapter premises implies only the
   bounded model claim.
2. **Instrument qualification.** Independent engineering evidence qualifies a
   named deployment of crypto, key custody, clock, storage, executable pinning,
   isolation, oracle custody and evaluator operation. This is configuration-
   scoped evidence, not a theorem about every Node, OS or organization.
3. **Causal occurrence.** A preregistered randomized and blinded occurrence
   supplies the actual outcomes and intervention contrasts. Statistical and
   causal conclusions remain bounded to the frozen population, model,
   mechanism and assumptions.

The subsequent typed occurrence bridge now proves the certificate-dependent
revision/runtime/arm bindings, the exact `1 + 4 + 4` modeled call projection,
the 300 exact analysis rows, and delayed/rollback equality to the complete W0
behavioral snapshot including its compiled readset. It derives the three exact
sign decisions from those rows rather than accepting free-standing exact-p
flags. It still does **not** prove a total real evidence graph: crypto,
execution, assignment, provider completeness, isolation, external truth,
causal credit, actual restore, LCB computation and independent analysis remain
separate named premises. Lean cannot manufacture historical execution, secret
custody, organizational independence, external truth, provider isolation or
finite-sample generalization.

The existing theorem
[`conditionalEvidenceBundleYieldsBoundedClaim`](../../formal/HSWMEndToEndRuntimeRefinement.lean)
already composes an exact claimed
runtime admission, Permit authentication, external truth/independent causal
credit, sealed behavior measurement and explicit revision attribution into a
bounded improvement claim. Its assumptions are correctly visible. The
subsequent occurrence bridge refines that free-standing attribution interface
into a typed four-arm witness while preserving the external identification
assumptions; the remaining delta is deployment and occurrence evidence, not an
unconditional theorem manufactured from status fields.

## 8. Falsification conditions

Validity is classified before efficacy. If the active revision fails to enter
the declared behavior readset, a required admission or reconstruction binding
is absent, leakage is detected, or the rollback root is not exact, treatment
adherence/integrity failed. The current occurrence is `VOID_PROTOCOL`, not a
negative efficacy result. Validly sealed operational missingness is
`INCONCLUSIVE_OCCURRENCE`; it is not completed by replacement or complete-case
analysis.

Only a complete integrity-valid occurrence can test the mechanism. Within that
scope:

- failure of `ACTIVE` to beat outcome-independent sham is a valid efficacy
  miss;
- an active advantage that is not separated from delayed-no-credit fails the
  temporal credit mechanism;
- an active advantage that is not separated from exact `W0` rollback fails the
  persistent-state mediation mechanism; and
- failure on an independently preregistered replication is preserved as a
  bounded replication failure rather than silently pooled away.

Those valid misses receive the frozen DNRD-5 non-GO disposition. A pattern
makes the tested mechanism family `RED_WITHIN_SCOPE` only when the
preregistered falsification contract declares that exact pattern a mechanism
failure; other non-GO patterns retain their exact terminal and enter an
explicit reroute decision without being renamed. Protocol/integrity breach or
leakage is `VOID_PROTOCOL`, validly sealed missing receipts are
`INCONCLUSIVE_OCCURRENCE`, and adapter drift is void or underdetermined
according to its declared scope. Downstream scale cannot rescue any category.

Safety, retention, calibration, cost and the stronger remove/re-admit test are
valuable future guardrails, but they are not fields of the frozen DNRD-5 GO
classifier. They must be added prospectively through `Inv` or a separately
preregistered protocol, never retrofitted after outcomes are observed.

## 9. What would count as a bounded positive result

A positive result may claim only:

> For the frozen model, runtime, task population, revision mechanism, oracle,
> probe suite and analysis contract, the genuine outcome-bound admitted
> successor caused a positive fresh-behavior score effect relative to the
> matched sham, delayed-no-credit and exact-rollback controls, under the stated
> integrity and causal assumptions.

It may not claim universal LLM improvement, truth of every learned claim,
benefit for every person or task, autonomous recursive self-improvement,
consciousness, FCL completion or full HSWM realization.

The work proceeds in this order:

1. **Completed formally:** define one typed efficacy-occurrence binding from

2. **Completed conditionally:** prove in Lean that a complete integrity-valid

   and terminal classification; every missing structural binding must fail

3. connect the complete execution-certificate producer and persistent Lean
   admission-decision evidence to the protected TypeScript/Effect commit;
4. add deployment-scoped adapter attestations for executable identity, keys,
   clock, storage/recovery, isolation and evaluator custody, retaining each as

5. independently replay the canonical evidence graph and classifier; and only
   then
6. run the preregistered real occurrence without changing thresholds, controls,
   retries or stopping rules.

Steps 1 and 2 fixed the efficacy mechanism before more adapter code. They do
not supersede the existing execution-
certificate, trusted-adapter or occurrence gates; steps 3 through 6 resume and
strengthen that same end-to-end sequence.
