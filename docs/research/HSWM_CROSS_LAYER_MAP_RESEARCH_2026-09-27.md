# 여러 층을 매핑하는 HSWM — 무엇을 생략해도 같은 질문에 답할 수 있는가

2026-09-27 · `SECONDARY_AI_RESEARCH_SYNTHESIS / EXPERIMENT_NOT_RUN`

[사용자 방향](../canon/USER_PRIMARY_HSWM_CROSS_LAYER_MAP_2026-09-27.md)은 물리·시냅스·Semantic
Weight 층 중 어느 곳에서도 출발하고, 층 사이를 매핑할 수 있는 HSWM이다. 이에 대한
연구 질문은 **특정 목적에서 생략 가능한 세부가 무엇이며, 생략한 뒤에도 예측·개입·학습이
얼마나 보존되는가**다. 아래는 그 질문을 구체화한 수학적 검토와 실험 설계다.

## 1. 세 층은 선택 가능한 모델링 관점이다

| 관점 | 모델에 넣을 수 있는 상태 | 선언해야 할 동역학·관측 |
| --- | --- | --- |
| 물리 | 선택한 입자·장·전기적 변수 등 | 어떤 물리 모형·해상도·경계조건에서 무엇을 관측하는지 |
| 시냅스·회로 | 연결 구조, 선택한 활성·전달·가소성 변수 | 연결도에 어떤 전이 규칙과 상태를 함께 주는지 |
| Semantic Weight | 역할을 가진 관계, 문맥·예외·근거와 revision | 국소 LLM이 읽은 의미가 공동 반응과 다음 상태를 어떻게 조건화하는지 |

이 표는 뇌의 보편적 세 모듈이나 실제 뇌와의 동등성 주장이 아니다. 시냅스 연결 목록에
어떤 동역학을 붙일지, 물리 상태에서 어떤 관계를 읽어낼지까지 별도 모델 선택이다.
의미 층에서 직접 작업할 때 모든 물리 상태를 먼저 생성할 필요는 없다. 반대로
Semantic Weight라는 이름만으로 실제 뇌의 모든 질문에 답할 수 있는 것도 아니다.

특히 **모델의 대상**, **실행하는 HSWM의 상태**, **현재 모델을 담는 저장 표현**을 구분한다.
하나의 HSWM은 뇌·사회·가상세계 등을 모델링할 수 있으며, 대상의 자료구조가 곧 그
HSWM의 전체 인지 상태라는 뜻은 아니다. 실행 본체에서는 기존 LLM-function·국소 입력·
outcome-bound revision을 유지한다.

## 2. M = Map을 연구 가능한 관계로 다루기

두 모델링 층을 A, B라고 할 때, 하나의 후보 매핑은 다음 내용을 가진다. 기존 schema의
atom·typed reference와 provenance로 표현할 내용이지 별도 runtime subsystem 명세가 아니다.

- 출발·도착 모델과 버전, 상태 정의역, 층·해상도·시간 단위;
- 상태 대응 `q`, 관측 대응, 허용하는 개입의 대응과 정의역 밖 입력;
- 관계 identity·참여 역할·순서·문맥·예외·근거 중 보존하는 것과 버리는 것;
- 직접 구성했는지 데이터로 학습했는지, 측정된 오차·미측정 영역과 복원 가능 범위.

매핑은 부분적이거나 다대일일 수 있다. 서로 다른 종류의 추상화가 교차할 수 있고,
역변환이나 모든 층의 일렬 순서를 요구하지 않는다. 역할을 표시한 incidence/factor
표현으로 동일 정보를 옮기는 일과, 미시적 차이를 버리는 coarse-graining도 구분한다.
전자는 [기존 표현 증명](HSWM_SEMANTIC_WEIGHT_DEFINITION_AND_HYPERGRAPH_2026-09-14.md)의
질문이고, 후자는 잃은 차이가 다음 행동에 필요한지까지 묻는다.

동등성 주장에도 수준이 있다. 주소가 연결됐다는 것, 선언한 정보를 복원한다는 것,
관측이 맞는다는 것, 개입 반응이 맞는다는 것, outcome 이후 학습이 맞는다는 것을
차례로 구별한다. 목적상 충분한 부분 매핑에 전체 가역성까지 요구하지 않는다.

## 3. 작은 반례: 압축된 상태만으로 다음 상태가 정해지는가

다음은 뇌 모형이 아닌, 두 Boolean 변수의 설명용 유한 모형이다.

```math
x=(a,b),\quad a,b\in\{0,1\},\qquad
q(a,b)=a,\qquad T(a,b)=(b,b).
```

`q`는 두 번째 변수를 버린다. `x=(0,0)`과 `y=(0,1)`은 모두 `q=0`이지만,
전이 뒤에는 `q(T(x))=0`, `q(T(y))=1`이다. 따라서 거시 상태 `0`만 받는 결정적 함수
`F`는 두 경우의 다음 거시 상태를 모두 맞힐 수 없다.

일반적으로 고정된 결정적 `T`와 `q`에 대해, 도달 이미지 `q(X)` 위에서

```math
F\circ q=q\circ T
```

인 `F`가 존재하려면, 같은 `q` 값으로 합쳐진 모든 상태에서 `q(T(x))`가 같아야 한다.
이 조건이 성립하면 `F(q(x))=q(T(x))`로 정의할 수 있으므로 충분하기도 하다.
전이와 매핑이 부분 함수라면 주장하는 닫힌 정의역부터 한정해야 한다.

이는 [기존 이론 기반의 P1](HSWM_SEMANTIC_WEIGHT_THEORETICAL_FOUNDATIONS_2026-09-14.md)에
대응하는 결정론적 특수 경우를 풀어 쓴 것이며 새 Lean 검증 결과가 아니다. 같은 국소 읽기로 합쳐진
상태의 서로 다른 목표 반응을 복원할 수 없다는
[`no_read_only_decoder_for_lost_distinction`](../../formal/HSWMSemanticWeightDefinition.lean)과
같은 정보 손실 문제를 층간 전이에 적용한다.

이 반례는 의미 층에서 직접 시작하는 접근을 반박하지 않는다. **어떤 차이를 생략해도
되는지**를 판별한다. 필요한 문맥·이력이나 추가 관측으로 상태를 보강하는 방법,
조건부 분포를 예측하는 방법, 질의 범위를 좁히는 방법은 각각 별도 후보가 된다.
다만 확률적 거시 전이를 쓰려면 숨은 변수의 분포와 개입에 따른 변화까지 명시해야 한다.
현재 자료에서 얻은 평균 성공률만으로 모든 개입에 충분한 상태라고 결론낼 수 없다.

## 4. 원 논문과 연결되는 정확한 부분

Rubenstein 등의 [Causal Consistency of Structural Equation Models, UAI 2017](https://staff.fnwi.uva.nl/j.m.mooij/articles/camera_ready_uai2017.pdf)은
상태 매핑과 순서를 보존하는 전사 개입 매핑 아래 두 SEM의 개입 후 분포가 일치하는
exact transformation을 정의한다. 여기서 순서는 개입의 포함 관계이며, 임의의 시간적
연산 합성이 자동 보존된다는 뜻이 아니다. 허용 개입 집합을 넓히면 동일한 매핑의
exactness가 깨질 수 있다. HSWM에는 ‘어느 개입에서 두 층이 같은 질문에 답하는가’라는
비교 기준으로 연결한다.

Beckers·Halpern의 [Abstracting Causal Models, AAAI 2019](https://ojs.aaai.org/index.php/AAAI/article/download/4117/3995)는
exact transformation만으로 직관적인 추상화가 충분히 제한되지 않는 사례를 논의하고,
uniform·strong·constructive abstraction 등을 구분한다. 상태 매핑과 개입 대응을 따로
편리하게 정해 얻은 분포 일치를 곧바로 모든 문맥의 구조적 동등성으로 읽지 않아야 한다.

두 논문의 대상은 명시된 가정을 가진 인과 모형이다. 아래 HSWM의 순차적·학습하는 LLM
동역학에 그 정리를 그대로 적용했다고 주장하지 않는다. 모델 상태, 외생 변수,
개입 대응과 학습 후 조건을 구체화하는 일이 추가로 남는다.

고정된 결정적 후보에서는 비교할 두 경로를 다음처럼 적을 수 있다.

```math
q(T_A(x,u))\quad\text{와}\quad T_B(q(x),\alpha(u)).
```

`u`는 선언한 제어·개입이고 `α`는 그 대응이다. 두 경로의 상태 전체를 비교하기 어려우면
미리 정한 관측 함수와 거리로 평가한다. 그때 입증하는 것은 해당 관측의 일치다.
확률 모형에서는 같은 외생·개입 조건하의 pushforward 분포를 비교한다.

**학습은 추가 질문이다.** 현재 예측이 같은 두 상태도 outcome 이후에는 서로 달라질 수 있다.
현재 전이의 일치가 revision의 충분성을 보장하지 않는다는 기존
`same_behavior_does_not_imply_same_learned_successor` 반례를 유지한다.

## 5. 다음 실험 — 같은 질문을 다른 층에서 풀고 revision을 옮길 수 있는가

**상태: 설계 후보, 미실행.** 물리적 뇌 재현으로부터 시작하지 않고, 알려진 미시 전이와
개입을 가진 작은 합성 세계에서 mapping loss를 식별한 뒤 실제 LLM을 연결한다.
합성 세계의 ‘물리 층’은 실재 물리학·뇌의 충실도 증거가 아닌 시험용 이름이다.

먼저 유한 세계에서 보존 가능한 매핑과 위 반례처럼 필수 변수를 잃는 매핑을 구성한다.
직접 의미 상태를 구성한 경로도 동등한 출발점으로 둔다. 물리→회로→의미의 전 단계를
거쳐야 참가할 수 있게 만들지 않는다. 모든 후보는 같은 질의·관측·개입 범위를 선언한다.

그다음 의미 관계를 실제 LLM이 읽고 예측하게 한다. 학습 split의 외부 outcome으로 관계를
수정한 뒤 후보를 고정하고, 새 개입·문맥 조합에서 결과를 비교한다. 관측 outcome과
agent가 가상으로 만든 rollout은 출처를 나누며, 상상한 결과를 실제 관측으로 쓰지 않는다.

| 대조 | 분리하려는 효과 |
| --- | --- |
| 역할·예외를 보존한 매핑과 직접 의미 상태 | 다른 층을 거치는 접근의 추가 비용·정보·재사용 효과 |
| 같은 정보를 담은 factor/incidence 표현 | 저장 형식 자체의 차이와 정보량 차이 |
| 필수 변수를 생략한 매핑 | 압축 때문에 생긴 전이·개입 실패 |
| 역할 또는 대응을 섞은 매핑 | 매핑의 의미가 실제로 사용되는지 |
| revision 없음·제거·복원 | outcome-bound 수정이 다음 행동에 기여하는지 |

직접 의미 상태가 더 잘하거나 동일하게 작동해도 사용자 목표의 실패는 아니다.
반대로 다른 층에서 추가 정보를 받은 군의 우위를 매핑 알고리즘 자체의 우위로 해석하지 않는다.
같은 정보 비교와 제한된 관측 비교를 별도로 보고하고, 모델·context·호출·토큰·매핑 생성
비용을 함께 결속한다. 단순 쌍별 clique의 정보 손실을 모든 이항 그래프의 한계로 확대하지 않는다.

주요 측정은 선언한 개입에서의 **두 경로 예측 불일치**, held-out outcome 정확도,
revision 전후 유지·전이, 손실·미지원 질의 비율이다. 확률 출력일 때만 분포 오차와
calibration도 측정한다. 실패 사례를 미지원으로 사후 재분류해 정확도를 올리지 않는다.

실행 전에 세계·매핑 버전, train/heldout 개입 분할, metric·허용 오차, 반복 수와 종료 규칙을
고정한다. 독립 outcome이나 충분한 검정력을 확보하지 못한 비교는 미판정으로 남긴다.
정확 매핑을 주장한 유한 범위에서 하나의 반례가 나오면 그 주장은 실패한다. 경험적 효과는
사전 선언한 기준에서 판정하며, 섞은 매핑과 차이가 없으면 그 기전의 추가 기여는 미지지다.
실패한 기전만 [적응 연구 전략](../canon/HSWM_ADAPTIVE_RESEARCH_STRATEGY_2026-08-30.md)에 따라 교체한다.

## 6. 현재 도구와 연구 상태의 연결

기존 [Inspect/GEPA 연결](../../_research/gepa_relation_comparison_v1/README.md)은 동일한 W1 E1
입력에서 관계 텍스트 후보를 비교하는 첫 실행 도구로 재사용할 수 있다. 현재 bridge는
다층 상태 전이, 일반 개입 또는 durable canonical revision을 실행하지 않는다. 위 설계의
모든 대조군과 전체 학습 폐루프가 이미 구현됐다는 뜻은 아니다.

2026-09-27 직전 점검에서는 DGX 모델 서버는 응답했으나 data-01 저장소 preflight가 실패했다.
이번 작업은 새로운 모델 요청 없이 개념·출처·연구 설계를 정리했다. 실제 실행은 적절한
환경을 확보하고 해당 모델링 과제의 adapter를 구성한 뒤 진행한다.

[OpenCog Hyperon 직접 비교](HYPERON_2026_DIRECT_PRIOR_DEEP_DIVE_2026-08-20.md)는 계속 필수다.
기존 audit의 metagraph·neural bridge와 exact component 버전·성숙도를 비교 대상으로 유지한다.
새 실행 baseline을 확보하지 않은 지금은 새 비교를 수행했다고 기록하지 않는다.

이번 노트는 국소 읽기 충분성, CR의 outcome-bound revision, FCL-2·6·8의 합성·세계/자기
모델 질문을 연결한다. CR-0..7·FCL-1..8 전체 판정, 뇌 실현·의식·전체 우주 시뮬레이션의
증거는 추가하지 않는다. 본체 연구를 대신하는 새 gate·승인 체계도 추가하지 않는다.
