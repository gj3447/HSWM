## 0. 답부터

`H/W/A/F/Π`는 **서로 독립인 다섯 실체도, HSWM을 표현하는 유일한 최소
좌표계도 아니다.** 현재 방어 가능한 가장 강한 문장은 다음이다.

> **`H/W/A/F/Π`는 하나의 token-native 학습 폐루프 안에서 relation identity,

이 판정은 5역할을 폐기하지 않는다. 독립성과 유일성이라는 과잉 주장을 제거하고,

계산 모듈이라는 뜻이 아니라, 정책 표현 위치와 무관하게 ordinary learning이 우회하지
못하는 집행 경계를 뜻한다.

subsystem이 아니라 한 대상의 작동 관점이다.

### 1.2 현재 문서가 실제로 허용하는 증거

## 2. 독립성이라는 말의 여섯 의미

같은 `독립`이라는 단어를 섞으면 판정이 틀어진다.

| 독립성 종류 | `H/W/A/F/Π` 판정 | 이유 |
|---|---|---|
| 의미적 역할 구별 | `CONDITIONAL_PASS` | 다섯 역할은 서로 다른 설계 질문에 답한다. |
| canonical ownership | `CONDITIONAL_PASS` | record, disposition, activation, proposal, permission의 정본 소유자를 나눌 수 있다. |
| 통계적 독립 | `NOT_DEFINED / FAIL_AS_CLAIM` | joint distribution과 조건부 독립 가정이 정의되지 않았다. |
| 인과적 독립 | `FAIL` | 서로를 조건화하는 것이 HSWM 폐루프의 핵심이다. |
| 물리적 저장 분리 | `FAIL_BY_DESIGN` | derived projection과 runtime cache가 다른 역할 정보를 가질 수 있다. |
| 표현·좌표의 유일성 | `FAIL` | 행동등가 re-encoding과 저장소 내부 대안 좌표계가 존재한다. |

따라서 `W_e != θ_e != U_e != A_e != Π_e`는 확률적 독립을 뜻하지 않는다.
truth, causal efficacy, evidence, activation, permission을 같은 scalar로 alias하지 말라는
**typed non-aliasing** 규칙이다.

## 3. 유일성을 깨는 내부 gauge 반례

### 3.1 `H ↔ W`: topology와 gate

relation을 `H`에서 제거하는 것과 `H`에 남겨 둔 채 `W.α`를 닫는 것은 특정 관찰
계약 아래 같은 forward behavior를 낼 수 있다. topology epoch, provenance, rollback을
관찰하지 않으면 두 표현을 행동만으로 식별할 수 없다.

### 3.2 `H ↔ A`: 현재 활성과 transient relation

현재 coalition을 별도 `A_t`에 materialize하거나, timestamped `Active(v,e,t)` relation으로
`H`에 기록하거나, immutable event log의 frontier에서 재구성할 수 있다. 지속성·복원 비용은
달라도 같은 episode output을 낼 수 있다.

### 3.3 `W ↔ F`: basis와 operator placement

가역 port 변환 `G`가 있을 때 다음 두 표현은 같은 합성 operator를 이룬다.

```math
F(Wa)=(F\circ G^{-1})(GWa)
```

typed basis, normalization과 parameter ownership을 고정하지 않으면 어느 부분이 `W`이고
어느 부분이 `F`인지 외부 행동만으로 식별되지 않는다. 범용 LLM interpreter를 `F`에 두고
전문 program을 `H`에 executable data로 reify하는 대안도 있다.

### 3.4 `Π` 표현 ↔ 집행 경계

policy description은 `H`의 node/relation, 별도 table, `F` wrapper 또는 numeric mask로
compile할 수 있다. 그러나 표현 이동 가능성은 집행 경계까지 learned core에 흡수해도 된다는
뜻이 아니다. capability, consent, provenance integrity, rollback을 승인하는 trusted path는
ordinary reward가 우회할 수 없어야 한다.

`H`의 provenance에 authority, grant, revocation 또는 capability claim이 기록되는 것과
현재 effect를 허용하는 것은 다르다. `H`는 누가 언제 무엇을 주장·부여·철회했는지의
history와 typed reference를 소유하고, `Π_t`는 그 record와 current mandate를 해석해
effective allow/deny와 commit을 소유한다.

### 3.5 저장소 내부의 직접 반례

[`cellular target 형식`](../../_research/root_compat/DEFINITION_HSWM_CELLULAR_METANEURAL_SYSTEM_2026-07-26.md)은
다음 10-tuple을 사용한다.

```math
\Omega_t=(F,H,\mathcal W,\alpha,A,S,Z,M,G,P)
```

[`통합 수학 문서`](../canon/HSWM_MATH_DEFINITION_UNIFIED_2026-07-26.md)는 이를 5-tuple과
경쟁하는 오류로 폐기하지 않고 target 확장과 구현 투사라는 서로 다른 좌표계로 둔다.
5-tuple의 유일성은 외부 선행연구를 호출하기 전에도 이미 저장소 내부에서 기각된다.

## 4. product가 아니라 dependent state

단순 표기 `S_t=(H_t,W_t,A_t,F_t,Π_t)`는 다섯 임의 값을 자유롭게 조합할 수 있다는
Cartesian product 주장이 아니다. 더 정확한 타입은 다음과 같은 dependent sum이다.

```math
\mathsf{HSWMState}
=
\sum_{H:\mathcal H}
\sum_{\Pi\in\mathcal P(H)}
\sum_{F\in\mathcal F(H,\Pi)}
\sum_{W\in\mathcal W(H,F,\Pi)}
\mathcal A(H,W,F,\Pi)
```

- `H/F`는 node, relation, port와 admissible function signature를 정한다.
- `Π`는 어떤 incidence, invocation, update가 허용되는지 제한한다.
- `W`는 그 정의역 위의 semantic transport와 learned disposition이다.
- `A`는 유효한 `H/W/F/Π` 위에서 실제로 점화된 bounded cut이다.

이 형식은 역할을 합치지 않으면서도 독립성 과장을 제거한다.

## 5. `HWAFN`의 `N` 판별

2026-08-26 supersession 전 canonical state 표기는 `H/W/A/F/Π`였으며 literal `HWAFN`은
당시 정본 객체가 아니었다.

| `N` 의도 | 판정 |
|---|---|
| network | `H/W/A/F`가 `Π` 아래 실현한 전체 network 또는 compiled projection이므로 독립 축이 아니다. |
| neural | HSWM 전체의 작동 관점이므로 중복이다. |
| norm | `Π`의 별칭으로 쓸 수 있지만 consent·authority·rollback 의미를 그대로 보존해야 한다. |
| learning/update | 실제 필요한 상위 법칙이지만 snapshot 성분보다 transition/learning signature로 두는 편이 맞다. |
| `\mathcal N_t` | 인류보편체가 provenance·권한 아래 수용하는 인터넷 network projection이며 HSWM cognition primitive가 아니다. |

따라서 `N`을 `Π` 대신 다섯 번째 문자로 놓는 것은 의도를 먼저 고정하지 않으면 잘못된
동형 표기다.

## 6. snapshot과 열린 동역학을 함께 닫는 signature

5-tuple은 snapshot 좌표다. 전체 HSWM을 정의하려면 observation, action/readout, transition,
outcome attribution과 constitutional constraint도 함께 적어야 한다.

```math
\Sigma_{\mathrm{HSWM}}
=(\mathcal X,\mathcal I,\mathcal O,\mathcal Y,\mathcal T,
  \mathsf{Step},\mathsf{Learn},\Pi^*)
```

| 기호 | 소유 의미 |
|---|---|
| `S_t∈\mathcal X`, `S_t=(H_t,W_t,A_t,F_t,(\Pi^*,\Gamma_t))` | 시점별 admissible versioned state |
| `\mathcal I` | token, observation, event의 typed input interface |
| `\mathcal O` | HSWM이 낸 token, action, tool call과 fallible readout의 typed output interface |
| `\mathcal Y` | environment 또는 역할 분리된 evaluator가 반환하는 outcome space |
| `\mathcal T` | outcome 전에 seal되는 typed trajectory space |
| `\mathsf{Step}` | 한 episode 안의 admissible forward transition |
| `\mathsf{Learn}` | pre-outcome trace, attribution, validation, rollback을 거친 durable learning law |
| `\Pi^*` | ordinary learning이 약화할 수 없는 identity-bearing meta-invariant |

`τ_t∈\mathcal T`는 `\mathsf{Step}` 전이와 그때 방출한 `\mathcal O`의 provenance-bound
유한 경로를 outcome 도착 전에 seal한 것이다. `y_t∈\mathcal Y`는 그 뒤 환경 또는
역할 분리된 evaluator가 돌려준 값이므로 output과 outcome을 같은 변수로 alias하지 않는다.

```math
\mathsf{Step}\subseteq
\mathcal X\times\mathcal I\times\mathcal X\times\mathcal O,
\qquad
\mathsf{Learn}_{\Pi^*}\subseteq
\mathcal X\times\mathcal T\times\mathcal Y\times\mathcal X
```

관계 표기는 partial·nondeterministic transition을 허용한다. 결정적 함수나 RNG/model
version까지 provenance에 결속한 stochastic kernel은 이 관계를 구체화한 realization이다.

`Γ_t`는 운영 state이지만 `Π*`는 모든 state 조합과 transition을 허용하는 invariant에 가깝다.
이 구분은 `Π`를 여섯 번째 subsystem으로 만들지 않는다. 한 시스템의 mutable state와
admissibility condition을 타입상 분리할 뿐이다.

헌법의 state update operator `U(S_t,τ_t,o_t)`와 `W`의 evidence/uncertainty channel `U_e`는
동일 문자가 다른 객체를 가리킨다. 앞으로 새 문서에서는 다음처럼 구분한다.

```text
Step / Learn_{Π*}    # episode transition / outcome-bound durable update
E_e 또는 Evid_e      # edge evidence, uncertainty, freshness, provenance projection
```

과거 문서와 hash-bound 기록의 기호를 소급 재작성하지 않는다.

## 7. canonical graph와 compiled plane의 계약

### 7.1 canonical native plane

`H`의 canonical 의미 단위는 stable identity, reified n-ary hyperedge, incidence별 role,
source/time, authority·grant reference와 attestation, supersession을 가진 record다. 현재
effective permission은 `Π_t`가 소유한다. pairwise projection만으로 복원할 수 없는 higher-order
구조가 있으므로 canonical record·lineage 단위를 clique graph로 낮추지 않는다.

### 7.2 role-preserving compiled plane

실행을 위해 다음 투사를 허용한다.

- hyperedge node를 명시한 incidence/star bipartite graph
- role/type별 sparse incidence matrix
- GraphBLAS-style semiring operator와 mask
- active subgraph, cache, materialized view와 incremental frontier
- LLM 입력을 위한 bounded serialization

compiled plane은 source snapshot, mapping version, loss declaration과 inverse 가능 범위를
가져야 한다. HSWM의 cognition, truth 또는 learning의 새 subsystem으로 부르지 않는다.

### 7.3 명시적 lossy plane

clique expansion, top-k neighborhood, embedding-only index와 narrative readout은 특정 질의를
위한 lossy projection이다. 이들은 canonical state를 조용히 덮어쓰거나 자신의 output을
evidence로 승격할 수 없다.

## 8. graph morphogenesis는 transaction이다

`ΔH`는 edge를 즉시 추가·삭제하는 단일 함수가 아니라 다음 transaction이어야 한다.

```text
typed proposal + match + authority + evidence
  -> precondition / dangling-context check
  -> conflict and critical-pair analysis
  -> candidate epoch
  -> outcome / retention / rights validation
  -> commit or reject / quarantine / rollback
```

DPO, SPO, SqPO는 삭제, unknown context, cloning의 의미가 다르다. HSWM은 rewrite family와
match semantics를 명시해야 한다. 두 local rewrite가 각각 valid하다는 사실은 병합 결과의
confluence, causal invariance, global capability invariant를 보장하지 않는다.

topology learning도 자유로운 adjacency 최적화가 아니다. 최소한 다음 목적을 동시에 관리한다.

1. long-range bottleneck과 oversquashing 완화
2. semantic locality와 role distinction 보존
3. sparse active computation 유지
4. provenance와 contributor identity 보존
5. `Π` capability·consent·rollback invariant 보존

## 9. runtime plane의 최소 분리

다음은 같은 HSWM의 projection이지 독립 인지 subsystem이 아니다.

| plane | 공학 역할 | 금지되는 과대해석 |
|---|---|---|
| canonical event/commit plane | version, lineage, provenance, rollback source | 기록이 곧 truth·learning이라는 주장 |
| compiled sparse neural plane | incidence transport, aggregation, role operator | matrix가 HSWM ontology 전체라는 주장 |
| ephemeral active plane | episode-local `A`, eligibility, logical frontier | 현재 context가 durable learning이라는 주장 |
| readout/index plane | 사람·agent가 읽는 탐색·직렬화·검색 | readout 편집이 canonical state 변화라는 주장 |
| enforcement path | capability, budget, consent, transaction validation | static harness가 cognitive route를 대신 작성 |

Differential Dataflow와 Naiad는 변화하는 graph의 반복·증분 계산을 유지하는 실행 선행이다.
GraphBLAS는 sparse graph computation을 generalized linear algebra로 compile하는 선행이다.
어느 것도 outcome-bound HSWM learning의 증거는 아니다.

## 10. 유일성·학습 주장 전 필요한 반증 시험

1. **encoding invariance**: native n-ary H와 role-preserving star/reified graph가 동일한
   provenance, output과 intervention response를 내는지 비교한다.
2. **projection collision**: nested hyperedge와 pairwise projection이 구분하지 못하는 구조를
   포함해 lossy plane이 canonical H를 복원한다고 거짓 주장하지 않는지 본다.
3. **boundary relocation**: `H↔W`, `A↔H`, `W↔F`, policy-description placement를 옮긴
   matched implementation과 비교한다.
4. **rewrite critical pairs**: 겹치는 `ΔH`가 순서에 따라 다른 상태를 만들 때 reject,
   scheduler, quarantine 또는 explicit branch가 동작하는지 본다.
5. **temporal reconstruction**: stored `A`와 event log에서 재구성한 activation이 같은 미래
   출력과 개입 반응을 내는지 본다.
6. **causal `W` mediation**: random gate, shuffled credit, degree-matched rewiring,
   remove/restore를 통해 `W -> A -> outcome`을 분리한다.
7. **memorization control**: retrieval, recurrence와 EdgeBank-style history-only baseline을
   이기지 못하면 continuous learning으로 세지 않는다.
8. **rights adversary**: 각각 local-valid인 concurrent edit가 merge 뒤 capability, consent,
   type 또는 lineage invariant를 깨는 경우를 만든다.
9. **fork/merge identity**: same snapshot/different lineage, shared lineage/different snapshot,
   member exit와 policy conflict를 분리한다.
10. **causal abstraction**: compiled plane에서 `abstract(do(x))`와
    `do'(abstract(x))`가 합의한 오차 안에서 교환하는지 본다.

이 시험을 통과해도 바로 유일성이 증명되는 것은 아니다. 관찰·개입·권리·감사 동치를 정의하고,
모든 admissible realization이 이 chart로 losslessly 들어오며, 대안 chart와 비교해
`unique up to typed isomorphism`임을 보이는 representation theorem이 추가로 필요하다.

## 12. closure의 정확한 상태

- `TARGET_IDENTITY`: token-native LLM-function macro-neural network와 outcome-bound
  evolving hypergraph learner라는 정체성은 유지한다.
- `DIRECT_EVIDENCE`: 이 감사는 새 효능 증거를 만들지 않는다. 현재 과학 상태는
  `UNJUDGED`다.
- `SUPERSEDED_CLOSURE_CANDIDATE`: `H/W/A/F/Π`를 의존형 canonical responsibility chart로,
  graph backend와 readout을 bounded projection으로 읽는 해석은 당시 정전과 선행연구를
  가장 적게 과장하려던 secondary proposal이었다.
- `PROPOSED`: rewrite transaction, compiled-plane receipt와 representation-theorem 시험은
  아직 구현·판정되지 않은 공학 연구 계약이다.
- `OPEN`: 5역할의 최소성, architecture-global identifiability, 대안 encoding 대비 우월성,
  intervention-preserving representation theorem과 `unique up to typed isomorphism`은 열려 있다.

최종 철학적 절단선은 다음이다.

> **하나의 HSWM은 하나의 폐루프다. 그러나 하나라는 사실이 내부 책임 좌표의 독립성이나
> 유일성을 뜻하지 않는다. 역할 분해의 목적은 세계를 다섯 물질로 나누는 데 있지 않고,
> 관계·효능·현재성·의미 실행·권리가 서로의 이름으로 위조되지 않게 하는 데 있다.**
