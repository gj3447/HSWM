## 2. 사용자 통찰과 해석

사용자는 “그 통계가 핵심이다”라고 하며, 뉴턴적 모델링에서 모든 양자 상태를 매번
계산하지 않는다는 비유와 LLM에 대한 통계적 압축 비유를 연결했다. 그 발화에서 읽은
핵심은 **많은 미시적 차이에서 유효한 통계적 구조를 추출하고, 이를 상위 상태와 규칙으로
조직하면 그 층에서 직접 모델링할 수 있다**는 것이다.

여기서 통계적 구조는 조건부 분포, 이력, 관계의 역할, 공동 조건과 예외까지 포함할 수
있다. 어떤 차이를 합칠 수 있는지는 목표 과제와 모델의 지원 범위에 달려 있다.
물리 비유를 단순 평균만으로 뉴턴 역학이 항상 나온다는 등식으로 해석하지 않는다.

AI가 제안하는 작업 흐름은 다음과 같다.

1. 원문·미시 모델·이력과 그 출처를 보존한다.
2. 과제의 예측과 행동에 필요한 통계적 구분을 찾는다.
3. 그 구분으로 상위 상태·관계와 전이 모델을 구성한다.
4. 지원 범위 안에서 상위 모델을 사용하고 총비용과 오차를 측정한다.
5. 새로운 질문·예외·오차가 생기면 보존된 원문이나 더 세밀한 모델을 조회한다.

이는 손실 압축을 역으로 풀면 모든 원문이 복원된다는 주장이 아니다. 학습 주장을 하려면
outcome에 결속된 graph revision과 이후 행동의 변화까지 따로 확인해야 한다.

## 3. 문헌에서 가져오는 연결

2026-09-29 확인한 1차 자료다. 표의 HSWM 적용은 논문 저자의 주장이 아닌 AI 제안이다.

| 출처 | 확인한 내용 | HSWM 연결과 적용 범위 |
| --- | --- | --- |
| [Shalizi·Crutchfield, 2001](https://arxiv.org/abs/cond-mat/9907176), computational mechanics | 미래의 조건부 분포가 같은 과거 이력들을 causal state로 묶는다. | 예측에 필요한 차이를 보존하는 상태 병합 기준. 해당 확률과정의 예측 충분성이지 실행 비용 최소성이나 모든 개입의 동등성은 아니다. |
| [Koch-Janusz·Ringel, 2018](https://arxiv.org/abs/1704.06279v2), information-theoretic renormalization | 재규격화에서 보존할 관련 자유도를 정보이론과 학습으로 찾는 방법을 다룬다. | 통계적 구조가 상위 변수 선택에 관여하는 사례. 고전 통계물리 결과를 LLM이나 HSWM의 검증 결과로 옮기지 않는다. |
| [Barnett·Seth, 2023](https://arxiv.org/abs/2106.06511), dynamical independence | 상위 자기 이력과 환경을 조건으로 미시 이력이 상위 예측에 더하는 정보를 평가한다. | 하위 상세를 계속 조회하지 않아도 되는 정도의 후보 진단. 필요한 이력·환경·추정 가정을 명시한다. 물리적 독립성 주장은 아니다. |
| [Rosas 외, 2024 v2 프리프린트](https://arxiv.org/html/2402.09090v2), hierarchical emergence | 정보·인과 상태·계산적 폐쇄성과 특정 추상화 수준의 lattice를 연결한다. | 여러 추상화 위치와 그 사이 변환을 탐색하는 근거 후보. 이산·정상 과정 등의 가정이 있고 임의의 축약에는 성립하지 않는다. |
| [Delétang 외, ICLR 2024](https://arxiv.org/abs/2309.10668), Language Modeling Is Compression | 확률 예측과 부호화에 의한 압축의 연결 및 실험. | 통계적 예측이 압축에 쓰이는 관계. 무손실 복원에는 모델과 부호화된 메시지가 필요하며 모델 가중치만으로 모든 원문을 저장한다는 뜻은 아니다. |
| [Li 외, ICLR 2023](https://arxiv.org/abs/2210.13382), Othello world representations | 수열 예측으로 학습한 모델에서 판 상태 표현을 발견하고 표현 개입으로 출력을 바꾼다. | 통계적 예측 학습과 세계 상태 표현이 양립하는 한정된 실증 사례. 모든 LLM의 인지 또는 HSWM 실효성에 대한 증명은 아니다. |

기존 문헌 노트의 [정보병목](https://arxiv.org/abs/physics/0004057)은 과제 관련 정보 보존,
[상태공간 압축](https://arxiv.org/abs/1409.7403)은 예측 정확도와 계산비용의 공동 고려에
연결한다. [Zurek의 고전적 상태 출현 논의](https://arxiv.org/abs/quant-ph/0105127)는 물리
비유의 조건을 보완한다. [Ted Chiang의 원문](https://www.newyorker.com/tech/annals-of-technology/chatgpt-is-a-blurry-jpeg-of-the-web)은
압축과 이해의 관계도 논하므로, 그가 모든 압축과 이해의 관계를 부정했다고 인용하지 않는다.

## 4. MAP의 데이터와 선택 정책을 분리하기

아래는 **설계 질문**이다. 기존 runtime schema에 임의 필드를 추가하거나 구현된 API라고
표시하지 않는다. 그래프 상태와 graph-resident program revision을 해석하는 TS/Effect
실행기의 책임도 유지한다.

| 구분 | 식별·보존할 내용 |
| --- | --- |
| 모델·원문 | stable ID, revision, 출처와 digest, 상태·관측의 의미 |
| 층간 변환 | source/target 모델, 과제·시간 범위, 보존/생략 정보, 역할·공동 조건·예외 |
| 상위 전이/readout | 축약된 상태와 필요한 이력으로 예측·행동하는 규칙 |
| MAP index | 현재 과제에서 모델·변환·원문을 찾는 참조와 검색 정보 |
| CHU 내 위치 선택 | 어느 후보와 해상도를 사용할지 조정하는 정책; 의미·원문·소유권 변경과 분리 |
| 평가 관측 | 해당 revision, 비교 과제·분포, 실제 오차·비용·불확실성과 반례 |

문헌의 lattice는 고정된 단일 층 순서를 강요하지 않을 근거 후보다. 그것이 CHU 자체의
정의나 구현이라고 단정하지 않는다. 여러 작은 관계가 역할과 조건에 따라 조합되게 하되,
연결 수가 적다는 사실만으로 좋은 구조라고 평가하지 않는다.

## 5. 평가 질문과 실패했을 때의 수정 후보

아래 항목은 측정기 개선을 위한 **미실행 제안**이다. 자동 계산되거나 점수가 갱신된 상태가 아니다.

| 평가 축 | 관측할 것 | 부족할 때 검토할 수정 |
| --- | --- | --- |
| 과제 보존 | 동일 held-out 질의·관측·시간 범위에서 세밀한 모델 대비 손실 | 병합 때문에 사라진 역할·조건·이력을 되살리거나 지원 범위를 조정한다. 평가 실패를 사후에 제외하지 않는다. |
| 하위 의존도 | 상위 이력에 미시 이력을 추가했을 때 예측이 개선되는 정도 | 빠진 상태·이력을 보강하거나 더 세밀한 모델을 선택한다. 유한 표본의 작은 개선량을 정확한 독립성 증명으로 쓰지 않는다. |
| 비자명성과 유용성 | 상수·무관한 잡음 표현을 넘어 실제 과제에 기여하는지 | 단순한 축약률이나 낮은 의존도만으로 높은 점수를 받는 후보를 제외한다. |
| 총비용 | 탐색·변환·실행·갱신·재조회·오류 복구 비용 | 반복되는 변환을 줄이거나 후보 위치·활성화 범위를 조정한다. |
| 예외와 복귀 | 범위 밖 입력 탐지, 드문 실패, 원문/세밀한 모델 접근 | 예외 참조와 재세분화 경로를 보완한다. 손실된 정보를 가역적으로 복원했다고 주장하지 않는다. |
| 조합과 활성화 | 필요한 공동 조건의 보존, 불필요한 활성화, 관계 누락 | 과활성 허브를 과제·문맥·역할별로 나누되 필요한 결합은 유지한다. |

기존 Cross-layer Map v1에서 `h`만 남긴 매핑은 `h` 전이는 보존해도 `fire`를 구별하는
`r`을 잃는다. 이 반례는 **상위 상태의 전이가 맞아도 과제 출력에 충분하지 않을 수 있음**을
이미 보여 준다. 이번 평가 질문은 그 구분을 문헌의 예측 충분성·폐쇄성 논의와 연결한다.
개입 과제에는 허용 개입과 미시 실현의 비교, 학습 주장에는 revision 제거·복원과 이후
held-out 행동 평가가 추가로 필요하다.

원문 보존 노트의 발화와 그 노트의 AI 작성 메타데이터를 구분한다. 본문은 원문 전체의

공유 KG 연결은 기존 publisher의 `ABOUT`, `REFERENCES`, `DERIVED_FROM`을 사용한다.
통찰 → HSWM은 `ABOUT`, 통찰 → 저장소는 `REFERENCES`이며, 저장소 위치와 이 문서의
경로는 통찰 기록의 후속 revision에서 찾는다. 문헌 → 통찰 → 원문의 기존 연결을 유지한다.
각 연결은 출처 있는 `PROPOSED` 관계이며 HSWM 정전의 변경이나 인과적 입증을 뜻하지 않는다.

로컬 [층간 Map ontology](../../ontology/identity/hswm_core/HSWM_CROSS_LAYER_MAP_ONTOLOGY.v1.json)는
별도 source-bound projection이다. 그 안의 UID를 라이브 KG에서 확인하지 못한 경우
존재한다고 가정해 edge를 만들지 않는다. 공유 KG와 저장소 그래프가 자동 동기화되거나
이 문서가 runtime의 활성 상태로 자동 주입되는 것은 아니다.
