## Protocol provisions still missing or requiring an implementation decision

1. The protocol names pins but does not yet give concrete model artifact, tokenizer hash/path, chat-template bytes, server executable/container digest, server flags, precision or deterministic-kernel policy. P0 must resolve this.
2. It lists transform classes but not exact transform bytes, bijections, role ordinal semantics, reference-evaluator mapping, or arm/block schedule. P1–P2 must resolve this before requests.
3. It defines E0/E1/E2 parser shapes but not their code locations, provider feature compatibility, private receipt boundary, or E2 request/call topology. P3 must fix these. If E2 becomes multiple calls, its new cost and failure surface is explicit.
4. It provides 2,784 proposed W1 requests only if E2 is one call. The recorder needs a separate census denominator, sentinel denominator, warm-up policy, timeout/retry policy, and treatment of server/model fingerprint change.
5. W2 calls an outcome “independent” without a concrete observer/generator/custody implementation. It also needs precise evidence payload equality across controls, sham semantic-equivalence witness, candidate-selection information boundary, and allocation/randomization seed.
6. Current semantic runtime cannot alter role bindings or exception references through `strictRevision`; W2 must either exclude those classes in its first implemented slice or define a separately reviewed schema/runtime extension before claiming to test them.
7. The protocol’s W2 statistical method is specified, but a pilot cannot both choose assumptions/sample size and use final-test information. P9 needs explicit pilot/final population separation and a deterministic implementation of the stated one-sided Bonferroni bounds.

These packages preserve the HSWM target: a canonical evolving hypergraph whose local LLM operator reads roles/context/evidence and whose outcome-bound revision changes later behavior. They only make its first two empirical links discriminable; they do not establish the target, causal credit, consciousness, or fractal closure.
