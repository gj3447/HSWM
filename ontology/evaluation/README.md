# Evaluation

Tests establish implementation invariants. Efficacy requires independently
measured outcomes, matched baselines, fresh evaluation, retention, canaries,
and removal ablation.

The current claim boundary is maintained in [`EFFICACY.md`](../../EFFICACY.md);
regressions and formal checks live in [`tests/`](../../tests/),
[`verification/`](../../verification/), and [`formal/`](../../formal/).
