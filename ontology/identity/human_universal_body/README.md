## Occam core: relations that make a difference

The proposed research title is **Relations That Make a Difference**. Its compact
engineering thesis is:

> **Semantic Weight = learned, role-conditioned causal difference.**

At the time, this did not replace the then-canonical `H/W/A/F/Π` identity. It removed duplicated
ontology around it: `H` addresses and preserves the relation, `W` is the
relation's recipient-sensitive disposition, `A` is its current finite
application, `F` realizes the local transition, and `Π` independently decides
what may be read, activated, learned, executed, or rolled back.

The KG therefore records a **Counterfactual Continuation Axiom** and one deletion
test: a mechanism belongs to the HSWM cognitive core only if matched
remove/restore changes later behavior and outcome-valid plasticity changes the
next episode. `W`, causal-efficacy evidence, truth support, activation, reward,
and permission remain separate channels. A measured effect never grants its own
legitimacy.

The proposed critical path is gate-relative: single-sweep n-ary noncollapse
(`SWM-0`) → bounded recurrent depth (`SWM-1`) → frozen typed LLM loop (`SWM-2`)
→ outcome-bound fast `W` (`SWM-3`) → only then slow `W`, `ΔH`, and federation.
Neo4j, Hyperon, self-modification, multi-agent orchestration, internet/sensor
federation, and the Human Universal Body runtime remain outside the first causal
path. They are deferred, not rejected.

## Semantic Weight is an operator, not a score

The KG records `W` as a macro-synaptic, role-aware set-to-set disposition: the
conditional capacity of a represented relation, in a specified context and
time, to change later activation and action. It explicitly separates:

| channel | meaning |
|---|---|
| semantic operator / `K` | role-aware transformation and contextual compatibility |
| `θ` | intervention- and outcome-supported causal efficacy |
| `U` | evidence, uncertainty, contradiction, freshness, and provenance |
| `A` | current volatile activation |
| `Π` | consent, capability, privacy, budget, promotion, and rollback boundary |

A high Semantic Weight is therefore not truth, moral worth, popularity, human
value, consent, or legitimate authority. Foundation-model parameters are
micro-weights inside an LLM cell; HSWM `W/H` are persistent macro-weights and
anatomy between typed semantic cells and participants.

## Deep Set-Hypergraph contract

The set carrier is a finite multiset of first-class incidence records, not a
bare node set. Every incidence retains member UID, relation UID, role,
direction, semantic type, time, scope, and provenance. Permutation invariance
applies only to arbitrary enumeration inside the same typed role-equivalence
class. It does not make roles or participants interchangeable.

A compiled neural pass may aggregate an incidence set, but the canonical
relation and its provenance remain recoverable. Each recipient gets a
role-specific message. Mean/sum/max pooling is only a control and cannot by
itself satisfy the target operator.

The proposed neural depth has three independent coordinates:

- semantic depth: repeated nonlinear member→hyperedge→member transforms;
- recurrent time: token, action, and outcome events re-enter the active field;
- structural scale: an HSWM can participate through typed ports in a larger
  HSWM without erasing its internal identity.

These axes are `SECONDARY_AI_PROPOSED`. A long path, repeated retrieval, nested
folder tree, multi-agent chat, or one pooled hyperedge is not by itself a deep
HSWM.

difference becomes visible and whose state can alter the next possibility.
Topology and routing must therefore remain auditable, appealable, forkable, and
bounded by capabilities rather than being treated as neutral optimization.

## Human Universal Body boundary

“One cognitive entity” means a difference-preserving causal integration, not
one owner, model, voice, database, objective, or compulsory membership regime.
A composite becomes an operational cognitive-unit candidate only when its
persistent whole-state makes a reproducible counterfactual difference to later
behavior while its parts retain identity, attribution, privacy, and exit.

This is not a claim of consciousness, personhood, metaphysical unity, or current
completion. Static information may participate causally without becoming an
independent subject. Universal scope is a compatibility and participation
horizon; it does not authorize involuntary ingestion, ownership transfer, or
unlimited retention. Open source does not automatically create legitimacy, and
rollback cannot undo harm already caused outside the graph.

## Validate and publish

Validate source hashes, UIDs, properties, frozen schema-registry tokens, and
relationship endpoints without writing:

```bash
uv run --extra kg python scripts/upsert_human_universal_body_ontology.py
```

Publish transactionally only with the explicit source configuration:

```bash
uv run --extra kg python scripts/upsert_human_universal_body_ontology.py \
  --apply --source-config ~/.config/symposium-ontology/source.yaml
```

The loader rejects duplicate UIDs and relations, uses one transaction, and
performs exact node/property and relationship readback. KG presence proves
publication only; implementation and efficacy still require code, tests, and
independent experimental receipts.
