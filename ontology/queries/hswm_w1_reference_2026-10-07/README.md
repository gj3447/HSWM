# W1 finite reference proof view

`hswm-workspace query w1-reference proofs` lists the 22 named Lean results,
their audited axioms, exact scope, source hash and revision. `comparison` returns
six groups of 128 actual TypeScript frames. `bindings`, `boundaries` and `lineage`
retain evidence identity, assumptions and the previous W1 progress view.

This additive view uses the existing RDF 1.1 / SHACL 1.0 / SPARQL 1.1 / PROV
projection. It does not replace the `progress` selection or promote T5. The
previous view is an explicit external anchor; its frozen bundle bytes are bound
as an artifact, rather than copying its observations into this view.

The mathematical scope is the authored finite Boolean reference. The adapter
checks actual objects and request composition finitely. Text-to-family semantics,
the JSON parser, general TypeScript refinement, shuffle-order correctness in
Lean, model behavior and efficacy are outside the proof. Root-targeted SHACL
checks reject removed evidence links and promotion of those boundaries.

Graph-validation output is derived and excluded from input bindings to avoid
a hash cycle. Mutable workspace navigation is not a scientific source binding.
