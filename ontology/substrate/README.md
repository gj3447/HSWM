# Substrate

The substrate preserves world observations, stable identity, provenance,
immutable cuts, and fail-closed readout. It provides something trustworthy for
the plastic field to learn over; it is not itself the completed learning loop.

Current anchors include [`world_ir.py`](../../world_ir.py),
[`world_compiler.py`](../../world_compiler.py), and
[`certified_readout.py`](../../certified_readout.py).
